# 0016. 画面の文言を今から翻訳できる形にする
## 背景
公開するなら最初から日本と英語圏で売る（2026-10-02 オーナー決定、売り方の資料（非公開））。今の画面の文言は日本語をコードに直接書いている。
## 決定
- これからの開発では、画面の文言を Xcode の翻訳用の一覧（String Catalog）に集める
- 今ある画面も、触るついでに少しずつ移す
- 英訳そのものは、公開すると決めた後（12月上旬以降）に Claude が行う。英語を話す友人がいれば確かめてもらう
## 理由
公開判断の後にまとめて移すと、課金や掲載用の素材の準備と重なって、3月中旬の公開に間に合わなくなるおそれがある。
## 影響・トレードオフ
- 開発の手間が少し増える
- 日本語の画面の見た目は変わらない
