# 0023. 一日の区切りを夜（初期 22:00）にし、設定で変えられるようにする
## 背景
[ADR-0005](0005-day-boundary-4am.md) で、一日は朝4:00に始まり翌3:59に終わると決めた。そのため、その日の点数・集中した時間・開けた時間・先週の自分との勝ち負けは、寝ている間の朝4:00に確定していた。夜に振り返りを見ても「今のところ」で、自己ベストを塗り替えても、塗り替えた手応えがないまま寝ることになる（2026-10-21 オーナーの声）。振り返りを見る時点で、その日の結果を確定させたい。
## 決定（2026-10-21 オーナー決定）
- 一日の区切りを夜の 22:00（初期値）にする。区切りの時刻で、その日の点数・集中した時間・開けた時間・勝ち負けが確定する。区切りの後に見る振り返りは確定した結果で、「今のところ・確定は朝4:00」はなくなる
- 区切りより後（例 22:00〜）の集中・デトックスは次の日の分。日の名前は区切りの後の暦の日（10/20 22:00〜10/21 22:00 が「10/21」。この名前の付け方は Claude 補足、Q46（非公開の判断表））
- 睡眠の点は一晩分まとめて起きた日に付ける（0:00 に寝て 7:00 に起きたら、7時間分がその朝の日。区切りより前に寝始めた分は寝た日に残す、Claude 補足、Q48（非公開の判断表））
- 朝の計画の全画面は、朝4:00以降にその日に初めて開いたときに出す（区切り〜3:59 には出さない）
- 区切りより後の予定（例 22:30〜23:30 の勉強）は、前の夜に振り返りの「明日の計画」で入れる。朝の計画の格子は起きてから区切りまで。習慣（PLN-08）のゲーム・SNS の時間は今までどおり最初から入る
- 区切りの時刻は設定で変えられる（20:00〜翌4:00、30分きざみ）。振り返りの通知の時刻の設定（REV-02）を置き換え、振り返りの通知も区切りの時刻に「今日の結果が確定しました」の文面で出す。ホームの「今日を振り返る」も区切りの時刻から出す
- 設定を変えたら次の日から効く（15:00 に 22:00 → 23:00 に変えると、今日は 22:00 で確定し、次の日は 22:00〜翌日23:00 の25時間、その先は 23:00 区切り）。今日の途中でゴールは動かさない
- 日ごとにその日の区切りを覚える（区切りの履歴を保存する。保存データの形が変わる、[data-model.md](../design/data-model.md) 第6版）。変える前の日（今までの記録）は朝4:00区切りのまま数え、点数・自己ベストは変わらない。先週の自分との比較は、切り替えた週だけ区切りがずれる
- 要件：GHO-17（区切りの時刻）・PLN-11（前の夜の予定）を足し、PLN-01・GHO-02・GHO-04・GHO-06・GHO-13・REV-01・REV-02・DTX-02・DTX-03・ANA-05・ANA-06 を直した（[requirements.md](../product/requirements.md)）。言葉は [glossary.md](../product/glossary.md) の「その日の区切り」
## 理由
- 振り返りを見る時刻に結果が決まるので、勝ち負けや自己ベストの更新をその夜のうちに味わえる
- ふつうの睡眠（区切りより後に寝始める）では、寝ている時間が一日の途中に来なくなる。睡眠を2つの日に分ける・夜中の睡眠を翌朝に数え直す、といった例外がなくなり、区切りの後に結果が変わらない（その日に一度も開かなかった日の睡眠を、あとで開いたときに保存する場合を除く）。区切りをまたぐ睡眠だけは Q48 の決まりで分ける
- 朝の「今日も頑張るぞ」は、朝4:00以降に出る朝の計画で残す
## 却下した案
- **12:00 始まり**（昼で区切る）：朝の計画が前の日の後半の計画になり、朝の「頑張るぞ」感が下がる
- **4:00 の区切りのまま、決着（勝ち負けの確定）だけ寝る時刻にする**：オーナーは区切りそのものを動かすほうを選んだ（区切りと確定の時刻がずれると、確定の後の時間がどちらの日の分か分かりにくい）
- **振り返りを開いたら締める／締めるボタン**：オーナーは時刻で自動に締めるほうを選んだ
## 影響・トレードオフ
- 区切りより後に起きている時間（夜更かし）は、次の日の分になる。夜中に集中すれば次の日の点が先に増える
- 前の夜の予定は朝の計画では入れず、前の夜の「明日の計画」で入れる。区切りから朝の計画を確定するまでは、その下書きで動く（PLN-11）
- 区切りの履歴を保存するので、保存データの形が変わる（マージはオーナーの確認後、ADR-0010 の例外）
- 区切りを変えた週は、先週の自分（とラップ）との比べ方がずれる。同じ時刻でそろえ、先週の日の始まりより前は0として比べる（GHO-02。Claude 補足、Q46）。自己ベスト・区間ベストなど、日をまたいで比べるものも同じ
- 区切りより前に寝始めた日（例 21:00 に寝る）は、区切りより前の分を寝た日に残し、起きた日には区切りより後の分だけ付ける（Claude 補足、Q48）
- ADR-0005 を置き換える
