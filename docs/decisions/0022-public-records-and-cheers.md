# 0022. ベストと今日を誰でも見られるようにし、応援でメタ報酬を返す
## 背景
[ADR-0017](0017-community-race.md) で、知らない人や友達とも対戦できるようにすると決めた。対戦の前に、SNS が使っている「メタ報酬」（報酬を与えたこと自体が報われる）を、少しずつアプリに入れたい（2026-10-21 オーナー）。最初の案は「自分のベストや今日の記録を誰かが開いたらインプレッションが記録される」しくみ。
一方で、誰が見たかを見せると「見たなら返さないと失礼」というメタ罰も生まれる。また GhostPace はゲームと SNS を止めるアプリなので、GhostPace そのものを確かめに開くアプリにしてはいけない。
## 決定
- 自己ベスト（1日のポイント、全期間）の日と今日は、基本は誰でも見られる。見せるのはポイント・推移の線・ラップの一覧だけで、カテゴリやブロックの名前・時刻ごとの内訳・集中や開けた時間は見せない
- つながりは片方向のフォロー（QR コードか ID、承認なし）
- インプレッションは1人1日1回で数え、件数だけ見せる。誰が見たかは見せない
- 応援は記録ごとに1回、取り消せる。受けた側には件数と応援した人の名前を見せる
- 応援してから7日以内に相手が自己ベストを更新したら、応援した側に「あなたが応援した○○さんがベスト更新」と出す（メタ報酬）
- インプレッション・応援・フォロー・メタ報酬は、プッシュ通知もバッジも出さず、アプリの中だけで見せる
- 段階4以降（同期 EXT-01 の後）。要件は SOC-01〜08（[social.md](../product/features/social.md)）
## 理由
- 「ただのポイント」なら他人に見せてもプライバシーの重さはほとんどない。何をしていたかが分かるもの（カテゴリ・ブロック名・時刻）は出さない
- 見られる側の報酬（件数）と、応援した側の報酬（ベスト更新が返ってくる）の両方を作ると、応援が続く。ケーラー効果（相手がいると頑張れる）とも合い、アプリの軸（過去の自分を超える）からずれない
- 誰が見たかを出さず、通知もしないことで、メタ罰と「確かめに開く」癖を避ける
## 影響・トレードオフ
- 記録の一部（ポイント）を端末の外へ送り、知らない人にも見せる。App Store のプライバシーの表示が変わる
- アカウントを作るので、アプリの中でアカウントを削除できる必要がある（Apple の決まり）。ニックネームとアイコンを見せ合うので、通報とブロックも要る（ADR-0017 と同じ）
- 通知しないので、応援やメタ報酬に気づくのは次に開いたとき。届いた感じは弱くなるが、SNS にしないほうを取った
- ポイントは睡眠やデトックスでも付くので、人によって付き方が違う。他人と並べたときの見え方は Q45（非公開の判断表）
- 課金の範囲（PAY-02 との関係）は後で決める（Q45）
