# 0017. 知らない人や友達とも対戦できるようにする
## 背景
ビジョンの「やらないこと」に「他人とのランキングや SNS 的な機能」があった。一方で、公開したときの有料の範囲に「コミュニティでの対戦」を入れた（PAY-02）。その範囲を 2026-10-03 にオーナーが決めた。
## 決定
- 将来、知らない人とも対戦できるようにする
- 友達は QR コードなどで追加して対戦できるようにしたい
- どちらも有料の範囲（PAY-02）。サーバーで記録をやり取りする必要があるので、同期（EXT-01、段階4）の後に作る。3月の公開には入らない
- ビジョンの「やらないこと」から「他人とのランキングや SNS 的な機能」を外す
## 理由
「負けられない」という気持ちを、先週の自分や目標だけでなく他の人にも向けられるようにする。売りの幅も広がる。
## 影響・トレードオフ
- 記録の一部を端末の外へ送ることになる（NFR-05「段階4までは外部に送信しない」の先）。App Store のプライバシーの表示も変わる
- 知らない人が名前やアイコンを見せ合う機能には、Apple の決まりで「通報」と「ブロック」の仕組みが要る
- サーバー代が毎月かかる。買い切りの人にもずっと開くかは、作るときに決める
