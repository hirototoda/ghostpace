# 0005. 日付境界は4:00
2026-10-21 に一日の区切りを夜（初期 22:00）に変えた（[ADR-0023](0023-day-boundary-evening.md)）。この ADR は当時の決定の記録として残す。0023 より前の日は、今も 4:00〜翌4:00 で数える。
## 背景
夜更かしする日がある。0時で区切ると、深夜の作業が翌日扱いになり計画・対戦がずれる。
## 決定
1日は4:00に始まり、翌3:59に終わる。計画画面の表示、セッションの日付、ゴーストの比較はすべてこれに従う。
## 影響・トレードオフ
4:00以降まで起きている日は扱いが不自然になる。頻繁なら設定で変更可能にする。
