# 0014. デジタルデトックスは、ブロックが効いていた時間で数える
## 背景
[ADR-0009](0009-reclaimed-time-no-measurement.md) では、タイマーを動かした時間を「取り戻した時間」とし、デトックスのカテゴリ（掃除・運動など）でタイマーを動かした時間を「デジタルデトックス」とした。その後 [ADR-0013](0013-hold-to-unlock.md) でゲームと SNS を24時間いつもブロックするようになった。オーナーが「ブロックが稼働している時間はデジタルデトックスとみなす」と決めた（2026-10-01）。
## 決定
- デジタルデトックスの時間＝いつものブロックが効いていた時間。長押しで開けていた時間と集中のタイマー中を除く。朝に決めたゲーム・SNS の時間（30分、1日3つまで）と寝ている間は、そのまま数える
- 対戦・グラフ・ポイント・振り返り・ホームの数字もこれに切り替える
- 寝ている間はポイントを半分にする。睡眠の区間はヘルスケア（なければ設定の時刻）から取り、朝の計画で確かめる
- デトックスのカテゴリのタイマーは残し、ポイントを1.5倍にする
## 理由
- いつものブロックが入った今は、ブロックの記録から「開けなかった時間」が分かる。タイマーを動かさなくても、遊ばなかった時間が数字になる
- 長押しで開けた時間が短いほど勝てるので、ブロックを開けない動機になる。決めた30分は不利益なく遊べるので、遊ぶならその時間に寄せる動機になる（2026-10-01 オーナー決定）
- 睡眠を数えると、よく寝る動機にもなる。ただ起きているときと同じ点にすると寝るだけで点が増えすぎるので、点は半分にした（上限を設ける案、同じ点にする案と比べて選んだ）
- 検討した他の案：数え方は変えず考え方だけにする、開けた時間を別の対戦項目にする（2026-10-03 に画面の数字としては採用した、ADR-0018）
## 影響・トレードオフ
- 2026-10-03：ホーム・振り返り・勝ち負けに出す数字は「開けた時間」に置き換えた（[ADR-0018](0018-show-opened-time.md)）。デトックスの時間はポイントの計算にだけ使う
- 2026-10-03：「寝ている間はポイントを半分」「カテゴリのタイマーは1.5倍」は、睡眠は最初の7時間0.75pt・8時間を超えたら0、タイマーは家事・運動・休みごとの1日の上限まで1.5倍に置き換えた（[ADR-0019](0019-points-diminishing-returns.md)）
- ADR-0009 の「デトックス＝カテゴリのタイマー」を置き換える。集中の数え方と金額（時給）は変えない
- 1日のデトックスが20時間前後になり、カテゴリのタイマーの時間とは桁が変わる。切り替える前の日と比べられないので、最初の1週間は先週のデトックスがない扱いになる
- 集中が増えるとデトックスは減る（二重に数えないため）。ポイントは集中の方が高いので損はしない
- ブロックの許可が外れていた時間は、GhostPace を開いて気づくまで分からないので、数字がずれることがある
