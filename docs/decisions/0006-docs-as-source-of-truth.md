# 0006. ドキュメントを唯一の仕様とする
## 背景
オーナーはコードを一切読まず、ドキュメントだけを読む。
## 決定
docs/ を仕様の正とする。振る舞いの変更は同じPRでドキュメントを更新する。作業ごとに docs/reports/ へ報告を書く。未決事項はClaudeが決めず、open-questions.md に追記する。
## 理由
オーナーが判断・確認できる唯一の手段がドキュメントのため。
## 影響・トレードオフ
ドキュメント更新の手間が増える。CLAUDE.md は最小限にし、詳細は docs/ に置く。
