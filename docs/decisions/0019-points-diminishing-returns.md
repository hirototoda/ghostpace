# 0019. ポイントは「やりすぎると1分の価値が下がり、開けるほど1回が重くなる」形で数える
## 背景
ポイント（GHO-14・DTX-03）は、集中もデトックスも続けるほど1分の点が上がる形（1時間ごとに×1.05 の複利）だった。2026-10-03 にオーナーと整理したところ、次の問題が見つかった（ふつうの日＝寝る7時間・集中4時間との差、Claude の試算）。
- 睡眠を短くするほど得をする（寝ている間0.25pt＜起きてブロック中0.5pt）。夜を2時間短くすると +8.6pt、睡眠を手で5分に直すと +18pt
- 何もしなくても点が増える：休みのタイマーをずっと動かすと +24.5pt、集中のタイマーをずっと動かすと +25.9pt
- 開けたときの損が、回数が増えるほど小さくなる（1回目9.5pt → 5回目1.0pt）。一度開けると「もうどうせ」になりやすい
- 目標のゴーストは「一度も開けない理想の日」で、1回でも開けると勝てなかった。また、目標を空き時間に足した分を集中とブロック中の両方で数えていた

将来は知らない人とも対戦する（[ADR-0017](0017-community-race.md)）ので、点の穴はそのまま不公平になる。

## 決定
経済学の「限界」（もう1単位増やしたときの価値や損）の考え方を入れる。良いことはやりすぎると1分の価値が下がり（逓減＝やるほど1分の点が下がる）、開けることは回数が増えるほど1回が重くなる（逓増＝開けるほど1回で引かれる点が増える）。
- 集中：10分1pt。1回で90分を超えたら×0.75、3時間を超えたら×0.5。1日で8時間を超えたら×0.75、10時間を超えたら×0.5。5分休めば1回目から数え直す
- 家事・運動・休みのタイマー：10分0.75pt。1日の上限は家事1時間・運動3時間・休み1時間
- ブロック中：10分0.5pt。続けたボーナスはなくす
- 睡眠：1回の睡眠の最初の7時間は10分0.75pt、8時間までは0.5pt、超えたら0
- 長押しで開けた：n 回目に n pt 引く
- 目標のゴースト：「計画どおりで、2回だけ開けた日」。空き時間は集中した割合だけを集中に数える
- 詳しくは [ghost-race.md](../product/features/ghost-race.md)「ポイント」と [digital-detox.md](../product/features/digital-detox.md)「ポイント」

## 理由
- 何もしないで集中のタイマーを回しても、1日の上限（8時間・10時間）より先は増えない（上限なしなら +36.5pt、この形なら +15pt まで）。こまめに止めて始め直す人は防げないが、その間はスマホを使えないので許容する（オーナー判断）
- 睡眠を削っても点は増えない（睡眠を短くすると7時間まで0.75pt を失い、起きていても0.5pt）。8時間寝て8時間集中した人（106.5pt）は、寝ないで90分＋5分休みを24時間続けた人（99.0pt）より高い。一番高いのは7〜8時間寝て集中10時間（109.5pt）
- 開けた損は回数が増えるほど大きく、開けた時刻（朝か昼か）に左右されない。倍々（1, 2, 4, 8…）は7回で127pt と1日分を超え、追いつけないと分かった時点でまた「もうどうせ」になるので見送った
- 目標のゴーストを「2回開けた日」にすると、計画どおりに過ごした日は、開けた回数でほぼ勝ち負けが決まる（オーナーの「1回くらいならボーナスで補ってギリ勝ちたい」）。1回なら、ブロック中に開けていた時間が40分未満で勝ち（10分なら +1.5pt）。2回なら、開けていた時間の分だけ負け（10分ずつなら −1.0pt）。日の形や開けた時刻（朝か昼か）には左右されない
- 検討した他の案：
  - 穴だけ塞ぐ（今の形のまま睡眠・タイマーに上限）：集中のずる（+23.7pt）と、開けた損の逓減が残る
  - 上限まで（目標を超えたら0点）：開けても損がほとんどなく、目標を超えて頑張る意味がない
  - 目標のゴーストのボーナスをなくす：4回開けても勝ててしまう
  - 寝不足の分を別に引く：睡眠の点がすでに下がっているので、二重に引くことになる（オーナー判断）
  - 集中の1日の上限を10時間・12時間：タイマーの8時間は休憩込みで約9.5時間で、「10時間を超えたら休んだ方がよい」に合う

## 影響・トレードオフ
- 2026-10-01 の「続けたボーナス（×1.05 の複利）」と「一時停止でリセットしない」、2026-10-02 の「目標のゴーストは一度も開けない理想の日」、[ADR-0014](0014-detox-is-blocked-time.md) の「寝ている間はポイントを半分」「デトックスのカテゴリのタイマーは1.5倍（上限なし）」、[ADR-0018](0018-show-opened-time.md) の「開けずに過ごしたご褒美はデトックスの点（続けたボーナスつき）」「目標のゴースト（一度も開けない理想の日）」を置き換える
- 1日の点の大きさが変わる（ふつうの日で約90pt → 約95pt。睡眠の点が上がり、ボーナスがなくなった）。点は保存せず毎回計算するので、先週の分も新しい決まりで比べ直す
- 開けた直後は点が下がるので、朝4:00すぐに開けるとその日の点がマイナスになることがある
- 数字（90分・3時間・8時間・10時間・上限・1pt の刻み）は仮の値。実機で使ってから見直す（Q25）
- 知らない人との対戦を作るときに、ずるへの強さをもう一度見直す
