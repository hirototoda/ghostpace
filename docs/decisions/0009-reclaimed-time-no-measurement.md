# 0009. 取り戻した時間はタイマー時間で数え、SNS使用時間は測らない
## 背景
「SNS やゲームに無駄にしていた時間をどれだけ減らし、意味のあることに使えたか」を時給換算で見せたい。iOS では、アプリ別の使用時間の生データを自分のアプリに取り込めない（[ios-constraints.md](../design/ios-constraints.md)）。
## 決定
タイマーを動かした時間を「取り戻した時間」とする。タイマー中は指定した SNS・ゲームをブロックするので、その時間は取り戻したとみなす。実際の使用時間の測定はしない。
## 理由
- iOS の制約を受けず、正確に記録できる
- タイマーがあればすぐ作れる。Screen Time API（段階2・実機のみ）を待たなくてよい
- 検討した他の案：iOS 標準の使用時間レポートを埋め込む（表示だけで記録には使えない）、「◯分使ったら知らせる」機能で近似する（15分単位程度と粗い）。どちらも手間の割に得られるものが少ない
## 影響・トレードオフ
- 2026-10-01：デトックスの数え方は [ADR-0014](0014-detox-is-blocked-time.md)（ブロックが効いていた時間）に置き換えた。集中の数え方は変えない
「実際に SNS を減らせたか」は分からない。タイマー外で SNS を使い込んでも金額は減らない。必要になったら段階3以降で近似値の併記を検討する。
