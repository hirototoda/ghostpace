# 0004. ブロック解除は常に許可し、記録のみ
## 背景
オーナーの選択：ブロックは自動開始＋タイマー中はさらに厳しく、ただし解除はいつでも可能。
## 決定
「厳しさ」は解除の難しさではなくブロック範囲の広さで表現する。解除は常に許可し、シールド表示と解除要求をすべて記録する。シールドには対戦状況を表示する。
## 理由
強制すると使うのをやめてしまうリスクがある。解除の記録は分析（ANA-01）と対戦種目（GHO-07）の材料になる。
## 影響・トレードオフ
抑止力は強制ブロックより弱い。効果が弱ければ、解除前の待ち時間などを後から検討する。

> 2026-10-01：「間を挟まない」は [ADR-0013](0013-hold-to-unlock.md)（長押し）に置き換えた。「解除は禁止せず記録する」はそのまま続く。
