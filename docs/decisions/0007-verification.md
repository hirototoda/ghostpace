# 0007. 検証はClaudeがシミュレーターで行い、実機専用項目のみオーナー
## 背景
別のアプリではClaude in Chromeでブラウザ確認をしている。同じように、Claudeが自分で動かして確認する体制にしたい。
## 決定
Claude in Chromeはネイティブアプリには使えないため、同等の役割をXcodeBuildMCPで担う。Claudeがビルド、テスト、シミュレーター起動、UI操作、スクリーンショット取得を行い、報告に画像を添付する。Screen Time APIなど実機でしか動かない項目のみ、オーナー向けの確認手順を報告に書く。
## 理由
オーナーがコードを読まない以上、「動いている証拠」を画像とテスト結果で示す必要がある。
## 影響・トレードオフ
段階2はオーナーの実機確認が律速になる。段階4でWebダッシュボードを作る場合は、そちらはClaude in Chromeで確認できる。
