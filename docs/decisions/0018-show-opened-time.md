# 0018. 画面にはデトックスの時間ではなく「開けた時間」を出す
## 背景
[ADR-0014](0014-detox-is-blocked-time.md) で、デジタルデトックスを「ブロックが効いていた時間」で数え、ホーム・振り返り・先週の自分との勝ち負けにもその時間を出すことにした。使ってみると、オーナーから「デトックスの時間は途中で開かない限りずっと増えていくので、開けた回数や時間を出す方がよいのでは」という指摘があった（2026-10-03）。
## 決定
- ホームの小さい数字・夜の振り返り・勝ち負けの「デトックス」を「開けた時間」に置き換える。例「🔓 開けた 25分 ［2回］」、一度も開けていなければ「開けていない」。ホームと振り返りで同じ言葉・形にする（回数は札にする案B）
- 開けた時間＝長押しで開けていた時間＋ゲーム・SNS の時間を過ぎても開いていた分。決めた30分は入れない。回数は長押しで開けた回数
- 勝ち負けは開けた時間が少ないほうが勝ち。先週のブロックの記録が丸1日分ない日は「先週の記録なし」
- デトックスの時間はポイント（DTX-03）の計算にだけ使い、画面には出さない
- 詳しくは [digital-detox.md](../product/features/digital-detox.md)「画面に出す数字（DTX-05）」
## 理由
- デトックスの時間はほぼ「24時間 − 集中 − 開けた時間」で、何もしなくても1日20時間前後になる。数字を見ても行動が分からない
- 集中が1時間増えるとデトックスが1時間減るので、集中を頑張った日に「集中は勝ち・デトックスは負け」と食い違う。開けた時間は集中と関係なく動く
- 毎日変わるのは開けた時間だけなので、それを直接出す方が分かりやすい。目標のゴースト（一度も開けない理想の日。2026-10-03 に「2回だけ開けた日」に変えた、ADR-0019）とも合う
- 開けずに過ごしたご褒美は、デトックスの点（続けたボーナスつき）としてポイントに残る（2026-10-03 に続けたボーナスはなくし、開けた回数で引く形にした、ADR-0019）
- 検討した他の案：今のまま（デトックスの時間）、デトックスの時間と開けた時間を並べる（意味の薄い20時間が残り、ホームの枠に入らない）、踏みとどまった回数（シールドの回数は目安でしかなく、開こうとするほど増える）、開けずに続いている時間（1日の比較に向かない）。ホームだけ「開けずに 3時間12分」にする案は、言葉を1つに絞るため見送った
- ADR-0014 で「開けた時間を別の対戦項目にする」を見送ったときは、集中との食い違いと「毎日ほぼ20時間」がまだ見えていなかった
## 影響・トレードオフ
- ADR-0014 のうち「ホーム・振り返り・勝ち負けにデトックスの時間を出す」部分を置き換える。数え方（DTX-01）とポイント（DTX-03）は変えない
- 「少ないほうがいい」数字になるので、0のときは「開けていない」と前向きに言い、開けたときも落ち着いた色にする（赤で責めない）
- Screen Time の許可を外していた時間は開けた時間に入らない（外れた時刻が分からないため）。その間はデトックスの点が付かないので、ポイントでは損をする
- 保存データの形は変わらない（ブロックの記録から毎回計算する）
