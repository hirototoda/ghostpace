# 0008. まず自分用に作り、手応えがあれば公開を検討する
## 背景
当初は自分専用で配布しない前提だった。オーナーから、似たアプリの良いところを取り入れつつ独自の機能（取り戻した時間の時給換算）で公開したいという希望が出た。
## 決定
段階1a〜3は自分用として作り、自分で1〜2か月使って効果を確かめる。手応えがあれば App Store 公開に向けた作業（初回の説明画面、プライバシーポリシー、課金、審査対応）を別の段階として計画する。
## 理由
10/12頃から使い始めるロードマップを崩さずに済む。自分で使って効果が出たという事実が、公開時の一番の根拠になる。
「手応え」の基準と、公開する場合の売り方は 2026-10-02 に決めた（売り方の資料（非公開））。
## 影響・トレードオフ
- 公開時に手直しが発生する。特に Screen Time API（Family Controls）は配布用の利用許可を Apple に別途申請する必要がある
- アイコンや名前は、ジャンルらしさ（時計・タイマー系のモチーフなど）は取り入れるが、特定のアプリと間違えさせる見た目にはしない。App Store の審査ガイドライン 4.1（模倣）や不正競争防止法に触れるおそれがあり、誤ってインストールした人の低評価はランキングにも逆効果なため
