# アプリのブロック

## 目的
ゲームと SNS を、開く前にひと呼吸おかせる。禁止はせず、開くには3秒の長押しと5秒の待ちを挟み、その間に先週の自分との差を見せて踏みとどまらせる。開いた事実は記録して、あとで分析と対戦に使う。

集中のタイマー中は、使うと決めたアプリ以外を全部ブロックする。いつものブロックが効いている時間は「デジタルデトックス」として数える（[digital-detox.md](digital-detox.md)、[ADR-0014](../../decisions/0014-detox-is-blocked-time.md)）。

## 今回作るもの（段階1a に前倒し、2026-10-01 決定）
Opal の「長押しで開く」を取り入れる。「タイマー中は広く」は下の「集中中は全部ブロック」として 2026-10-01 に決めた。

### いつもブロック（BLK-09）
- ゲームと SNS を **24時間いつも** ブロックする。計画やタイマーとは関係なく、時間帯も問わない
- 選ぶ画面は GhostPace の画面の中に iPhone 標準の選択画面を埋め込み、右上の「完了」で保存、「やめる」で何も変えない（2026-10-01、実機で標準の出し方だとすぐ閉じたため）
- 対象は iPhone 標準の選択画面で選ぶ（iOS の仕組みで、アプリから「ゲーム」「SNS」に印をつけておけないため）。選択画面の上に「『ソーシャル』と『ゲーム』に印をつけてください」と案内を出す
- 選択画面で Web サイトも選べる。選んだサイトも同じようにブロックする（Safari で SNS を開く抜け道をふさぎたいときに使う）
- 1つも選ばずに閉じたら始めない（「何も選ばれていません」と出す）
- ブロック中のアプリを開くと、iPhone が「シールド」という画面をかぶせる

### シールド（BLK-05）
| 場所 | 表示 |
|---|---|
| 見出し | ゲームと SNS はブロック中 |
| 説明 | 「今日は先週の自分より +20分」（先週のデータがなく目標があれば目標との差。どちらもなければ出さない）と、その下に「『開く』を押すと通知が届きます。通知か GhostPace を開いて、3秒長押しすると5秒後に開けます」（2026-10-01 実機で、押しても GhostPace が開かず分かりにくかったため追加） |
| 上のボタン | 閉じる（ホーム画面に戻る） |
| 下のボタン | 開く |

- シールドには文字とボタン2つしか置けない（iOS の制約）。長押しはシールドではできないので、GhostPace の中で行う
- 差の相手はホームの円と同じ（選んだ相手。その相手がいない日はいる方）
- 差の数字は、GhostPace が最後に記録を保存したときの値をもとに、その時刻の分まで計算する（タイマーが動いていれば、その分も足す）
- 朝4:00を過ぎて GhostPace をまだ開いていないとき（材料が前の日のもの）は、差を出さず説明の文だけ出す

### 長押しの画面（2026-10-01 決定：案A「円を押す」）
[案の比較](../assets/2026-10-01-options-hold-unlock.png)（左から A・B・C、右端は開けたあと。A に決定。B「今日の円＋横長のボタン」、C「暗い画面」と比べて選んだ）
- 上に「ゲームと SNS はブロック中」、その下に相手との差を大きく（リードは前向きな色、負けは落ち着いた色）
- 開ける長さ（5分〜1時間）を選ぶ欄、その下に押す円。押している間、円のまわりの輪が3秒で一周する。押し終わると円が「5・4・3・2・1」の数字に変わる
- いちばん下に「やめる」

### 開くまでの流れ（BLK-06〜08）
1. シールドの「開く」を押す → シールドが閉じ、「GhostPace で3秒長押しして開く」という通知が届く
2. 通知を押す（または2分以内に GhostPace を自分で開く）と、**長押しの画面** が出る
3. 開ける長さを選ぶ：**5分〜1時間、5分刻み**。初めは毎回15分に戻る（前回の長さは覚えない）。15分でよければ何もしなくてよい（2026-10-01 オーナー要望）
4. 円を **3秒以上押し続ける**。途中で指を離す・画面を閉じる・ホームに戻ると最初から。押し終わると **5秒数える**（この間に「やめる」を押す・ほかのアプリに移ると開かない。2026-10-01 オーナー要望で「5秒長押し」から変更）。円の上に「今日は先週の自分より +20分」を出す
5. 数え終わると選んだ長さだけ開く。画面に「開けました。ゲームや SNS を開き直してください」と、ブロックに戻るまでの残り時間を出す
6. 時間がたつと自動でブロックに戻る。使っている途中でもシールドが出る。iPhone の仕組みで分単位になるので、戻るのは選んだ時刻から最大1分遅れることがある（早く戻ることはない）

- 主な操作が「開く → 通知 → 長押し → 開き直す」と1つより多いのは、シールドの上に長押しを置けない iOS の制約による（[ADR-0013](../../decisions/0013-hold-to-unlock.md)）

- 長押しの画面は「やめる」でいつでも閉じられる（開かずに閉じたことも記録する）。開けたあとの画面は、時間が終わると自動で閉じる
- 朝の計画・振り返りなどほかの画面が出ているときに通知を押すと、その画面を閉じたあとに長押しの画面が出る
- 開いている間は、長押しの画面と設定に「あと12分でブロックに戻る」と「今すぐ戻す」を出す（2026-10-01 オーナー確認）
- 開いている間にもう一度開くことはできない（長押しの画面は残り時間と「今すぐ戻す」だけになる）。長さを変えたいときは「今すぐ戻す」のあとで開き直す
- タイマー中でも同じように開ける（禁止しない。[ADR-0013](../../decisions/0013-hold-to-unlock.md)）
- 通知を許可していないときも、「開く」から2分以内に GhostPace を開けば長押しの画面が出る（2026-10-01 オーナー確認）。設定の「アプリのブロック」からも開ける
- シールドから直接そのアプリには飛べない（iOS の制約）。開けたあと自分で開き直す

### 最初の設定（BLK-01）
- この機能が入った版を最初に開いたとき、1回だけ説明を出す：「ゲームと SNS をブロックします。開くときは3秒長押しして5秒待つ」→「続ける」で Screen Time の許可 → 対象を選ぶ画面
- 「あとで」を選んだら、設定の「アプリのブロック」から始められる。説明は二度と自動では出さない（2026-10-01 オーナー確認）

### 設定の「アプリのブロック」
| 行 | 内容 |
|---|---|
| 状態 | ブロック中／あと12分でブロックに戻る（今すぐ戻す）／まだ始めていない（始める）／Screen Time が許可されていない（設定を開く）／ブロックするアプリを読めなかった（選ぶ） |
| ブロックするアプリ | iPhone 標準の選択画面を開く。**選ぶ前に長押し（開くときと同じ3秒＋5秒）**（外せば長押しなしで開けてしまうため。2026-10-01 オーナー確認）。選択が読めなくなったときは外すものがないので長押しなし |
| 開ける | 長押しの画面を開く |
| 集中中も使うアプリ | 選んだ数（例：アプリ2、なしなら「なし（全部ブロック）」）。押すと iPhone 標準の選択画面（BLK-02） |

### 記録（BLK-06）
| 記録すること | いつ | 書く場所 |
|---|---|---|
| シールドが出た | ブロック中のアプリを開こうとしたとき（iPhone がシールドを出し直すたびに記録されるので、回数は目安） | シールド |
| 開くを押した | シールドの「開く」 | シールド |
| 長押しをやめた | 長押しの画面を開けずに「やめる」で閉じた（数えている途中を含む）。指を途中で離しただけでは書かない | GhostPace |
| 開けた | 長押しと数えが終わった。選んだ長さと、そのとき動いていた（一時停止を含む）タイマーの記録 | GhostPace |
| 戻った（時間切れ） | 選んだ長さがたって、ブロックに戻した | 自動で戻すしくみ |
| 戻った（今すぐ） | 「今すぐ戻す」 | GhostPace |
| 戻った（開いたとき） | GhostPace を開いたら期限が過ぎていたので戻した（自動で戻すしくみが動かなかったとき） | GhostPace |
| 始めた | いつものブロックを始めた（対象がない状態から選んだとき。BLK-11） | GhostPace |
| 選択が読めなくなった | 対象の選択が読めず、消した（このあとは選び直すまでブロックがない。BLK-11） | GhostPace・自動で戻すしくみ |
| 許可が外れた／戻った | GhostPace を開いたときに、Screen Time の許可が外れている・戻っているのに気づいた（BLK-11）。外れた時刻は分からないので、「外れた」には前に許可を確かめた時刻も書き、そこから外れていたとみなす。iPhone が許可を「未確認」と返したときは、1分以上続いたときだけ「外れた」と書く（「拒否」ならすぐ書く。2026-10-03、起動直後などに一瞬「未確認」と返り、誤って外れたと記録していたため） | GhostPace |
| ゲーム・SNS の時間で外した／戻した | 実際にいつものブロックを外した・かけ直した時刻（BLK-11）。合図が遅れたらその時刻で書く | 自動で切り替えるしくみ・GhostPace |
| （補足） | ゲーム・SNS の時間の中で開けた時間が終わったときは、「戻った」（開けていた状態が終わった）と「外した」の2行になる。ブロックはかからない | |

- 「戻った」は、開けていた状態をやめるときだけ書く（すでにブロック中なら書かない）。ごくまれに、自動と GhostPace がほぼ同時に戻して2行になることがある。分析では同じ期限のものを1回と数える

記録は消さない。何を記録したかは今は画面に出さず、デジタルデトックスの時間（DTX-01）と分析（ANA-01、段階3）で使う。集中中の全部ブロックはタイマーの記録から分かるので、ここには書かない。

- いつものブロックを止める操作はない（対象を変えることはできる。変える前に長押し）。アプリを消して入れ直すと記録も消え、対象を選び直したところから「始めた」になる

### 困ったときの決まり
| 場合 | どうなるか |
|---|---|
| Screen Time の許可を取り消した | ブロックは iPhone が外す。対象の選択と「始めた」は残す。設定の状態は「Screen Time が許可されていません　設定を開く」。許可し直すと、そのまま続きからブロックする |
| 通知を許可していない | 「開く」を押しても通知は届かない。2分以内に GhostPace を開けば長押しの画面が出る。設定の「アプリのブロック」の下に「通知がオフなので、『開く』のあとは自分で GhostPace を開いてください」と出す |
| 自動で戻すしくみが動かなかった（iPhone の都合で止まった等） | GhostPace を開いたときに期限を見て戻す。GhostPace を開かないあいだは開いたままになることがある（実機で確認する） |
| 開けている間に iPhone を再起動した | 期限はそのまま。時間がたてば戻る（実機で確認する） |
| 記録のファイルの1行が壊れた | その行だけ読み飛ばし、消さずに残す。次の記録は新しい行に書く |
| 対象の選択が読めなくなった | 開こうとしても外さない（外すとかけ直せないため）。「ブロックするアプリを読めませんでした。設定でもう一度選んでください」と出す。設定の状態は「ブロックするアプリを読めませんでした　選ぶ」 |
| 集中のタイマー中に GhostPace が落ちた・iPhone を再起動した | 全部ブロックはかかったまま（タイマーも動いたまま）。GhostPace を開いたときに、タイマーの状態に合わせてかけ直す・外す |
| 集中中に GhostPace まで止まった | 一時停止も長押しもできない。iPhone の設定 → スクリーンタイム → GhostPace の許可を外すと、全部のブロックが外れる（タイマーは動いたまま。GhostPace を開いて終える）。次から「集中中も使うアプリ」に GhostPace を入れてもらう（実機で最初に確かめる） |
| 集中中も使うアプリに入れたのに止まる | iPhone の既知の不具合（ほかの Screen Time を使うアプリの許可が残っていると起きるという報告がある）。起きたら、iPhone の設定 → スクリーンタイムで、ほかのアプリの許可を外してもらう（実機で確かめる） |
| ゲーム・SNS の時間の始まり・終わりの合図が届かなかった | GhostPace を開いたときに決定表で合わせる。デトックスは実際に外した・戻した記録で数えるので、遅れた分はデトックスに入らない |
| タイムゾーンが変わった | ゲーム・SNS の時間は保存した時刻（UTC）のまま。GhostPace を開いたときにスケジュールを登録し直す |
| Screen Time の許可が入っていない版（シミュレーターなど） | 設定の状態に「この版ではまだ使えません」。説明も出さない |

## 集中中は全部ブロック（BLK-04・BLK-02、2026-10-01 決定）
集中するときは、ゲームと SNS だけでなく、ほとんどのアプリを止める。ただし Kindle のように集中に使うアプリは、自分で決めたリストだけ使える。

- **いつ**：「集中に数える」カテゴリ（勉強・仕事・読書など）のタイマーが動いている間。デトックスのカテゴリ（掃除・運動など）のタイマーではかけない（いつものブロックだけ）
- **一時停止で外す**：一時停止を押すと全部ブロックは外れ、いつものブロック（ゲームと SNS）だけに戻る。再開するとまたかかる。タイマーを終えると外れる
- 予定の時間（カウントダウンの0）を過ぎて超過を数えている間も、かけたまま
- アプリのブロックを始めていない（Screen Time を許可して対象を選んでいない）ときは、かからない

### 集中中も使うアプリ（BLK-02）
- 設定の「アプリのブロック」の「集中中も使うアプリ」で、iPhone 標準の選択画面から選ぶ（例：Kindle・辞書・電卓）。**1つのリスト**で、どの集中のカテゴリでも同じ（カテゴリごとにはしない）
- 選択画面の上に「集中中も使うアプリ（Kindle・辞書など）を選んで、右上の「完了」を押してください。GhostPace も選んでおいてください」と出す。GhostPace まで止まると、一時停止も長押しもできなくなるため（iPhone が GhostPace 自身を止めるかは実機で確かめる。下の「困ったときの決まり」）
- 初めは空。空なら全部ブロックする
- 電話・メッセージなど、iPhone が止めさせないアプリは選ばなくても使える。Safari など、ほかにも止まらない iPhone のアプリがあるという報告がある（実機で確かめる）
- ゲームや SNS（いつものブロックで選んだもの）をこのリストに入れても、いつものブロックで止まったまま
- Web サイトは集中中に個別には止めない（いつものブロックで選んだサイトは止まったまま）
- 変えるのはタイマーを止めているときだけ（タイマー中は全画面のタイマーが出ていて、設定を開けない）。長押しは要らない

### 集中中に開きたくなったら
- いつもと同じ（シールドの「開く」→ 通知 → GhostPace で3秒長押し＋5秒 → 5分〜1時間）。禁止はしない（[ADR-0013](../../decisions/0013-hold-to-unlock.md)）
- 開けている間は全部開く（いつものブロックの分も）
- 時間がたって戻るとき（自動で戻すしくみ・GhostPace を開いたとき・「今すぐ戻す」）は、下の「今かかるブロック」の表で決める（まだ集中のタイマーが動いていれば全部ブロック、一時停止中・終えたあとならいつものブロック）
- 開けていた時間は集中の時間から引く（Q24。段階1b の金額表示で使う）
- シールドの見出しは、集中中は「集中中はブロック中」にする（説明とボタンはいつもと同じ）

## ゲーム・SNS の時間（BLK-10、2026-10-01 決定）
朝の計画で「この時間はゲームと SNS をしてよい」という時間を決め、その時間だけいつものブロックを外す。決めた時間にしか遊べないようにすると、ほかの時間に遊びたい気持ちがかえって薄れる（オーナーの考え）。

- **置き方**：朝の計画の「ブロックを追加」で、「何をする」の一覧に「ゲーム・SNS」を出す（[daily-plan.md](daily-plan.md)）。**長さは30分で決まり**、開始だけ選ぶ。**1日に3つまで**置け、並べてもよい（20:00 と 20:30 で1時間）。**習慣に入れておくと**、朝の計画に最初から入っている（2026-10-05 に前の日からの引き継ぎから変更、[daily-plan.md](daily-plan.md)「習慣」）。ほかのブロックと重ねられず、4:00 をまたげない（計画ブロックの決まりのまま）。テンプレートにも入れられる（3つまで）
- **不利益なし**：その30分は、遊んでいてもデジタルデトックスとして数え続ける（時間もポイントも。ブロック中と同じ10分0.5pt。[digital-detox.md](digital-detox.md)）。減るのは長押しで開けた時間と、開けた回数で引く点（DTX-03）だけ。予定の終わりを過ぎても開いていた分（合図の遅れ）は数えない（2026-10-01 オーナー決定）
- **その間**：いつものブロックを外し、ゲームと SNS が開く。始まり・終わりは iPhone のスケジュールで自動で切り替わる（GhostPace を開かなくてよい）。時刻は分単位。合図が届かなかったときは、GhostPace を開いたときに合わせる
- 並べたゲーム・SNS の時間（20:00–20:30 と 20:30–21:00）は、つながった1つの時間として切り替える（あいだでブロックしない）
- **集中が優先**：ゲーム・SNS の時間に集中のタイマーを始めると、全部ブロックになる。一時停止・終えると、ゲーム・SNS の時間に戻る
- タイマーは始められない（このブロックには開始ボタンを出さない）。計画の集中・デトックスの合計にも、目標のゴーストの「空き時間」にも入れない
- **確定したあとの変更**：
  | ゲーム・SNS の時間 | 消す | 足す・開始を動かす |
  |---|---|---|
  | まだ始まっていない | 自由 | 自由（3つまで。長押しは要らない、2026-10-02 オーナー決定） |
  | 今その時間の中 | 今の時刻で終える | できない（続けたいときは、次の30分を足す） |
  | もう終わった | できない（編集と削除を出さない） | できない |
  - 朝の計画の下書きの間とテンプレートの中は自由
- 計画なし日は、ゲーム・SNS の時間はない（いつものブロックが24時間）。あとから計画を作って確定すれば置ける（確定の前の下書きの間は自由に置ける）
- ゲーム・SNS の時間の間（集中のタイマーを動かしていないとき）に長押しの画面を開くと、「今はゲーム・SNS の時間です（20:30 まで）」とだけ出す。集中中なら、いつもどおり長押しで開ける
- いつものブロックを始めていない日は、置いても計画に出るだけ

## 今かかるブロック（決定表、2026-10-01）
どの合図（ゲーム・SNS の時間の始まり・終わり、開けた時間の終わり、タイマーの開始・一時停止・再開・終了、GhostPace を開いたとき）でも、この表で計算し直してかける。前の状態から差分を考えない。

| ブロックを始めた・許可あり | 長押しで開けている | 集中のタイマー（一時停止していない） | ゲーム・SNS の時間 | いつものブロック | 集中中の全部ブロック |
|---|---|---|---|---|---|
| いいえ | — | — | — | なし | なし |
| はい | はい | — | — | なし | なし |
| はい | いいえ | 動いている | — | かける | かける |
| はい | いいえ | 動いていない | 中 | なし | なし |
| はい | いいえ | 動いていない | 外 | かける | なし |

- 例：20:00–20:30 がゲーム・SNS の時間で、20:10 に集中を始めて 20:20 に終えた → 20:10〜20:20 は全部ブロック、20:20〜20:30 はなし、20:30 からいつものブロック
- 例：ゲーム・SNS の時間の中で開けた時間が終わった → まだゲーム・SNS の時間なのでブロックしない
- 例：開けている間にゲーム・SNS の時間が終わった → 開けた時間が終わるまではブロックしない

## 段階2に残すもの
- **計画ブロック中の追加ブロック**（BLK-03）：カテゴリごとに対象を足す。集中中の全部ブロックで足りれば作らない

## 注意
- ブロック対象のアプリ名は自分のアプリで読み取れない（iOS の制約）。記録に残るのは「どの対象か」の印だけ
- **実機でしか動作確認できない**。シミュレーターでは長押しの画面と設定の画面だけ確かめられる（手順は オーナーの作業一覧（非公開））
- **TestFlight の版でも使える**：Apple の許可（Family Controls (Distribution)）が 2026-10-01 に出て、4つの ID で使えるようにした（[ios-constraints.md](../../design/ios-constraints.md)）
