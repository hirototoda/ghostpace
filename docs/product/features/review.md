# 振り返り

## 日次（夜）
段階1a（簡易）：数字だけの1枚（2026-10-01 決定。原因のメモは取らない。数字がしっかり見えればよい、とオーナー。[画面](../assets/2026-10-01-options-owner-ideas.png)）
- 入口：ホームの「今日を振り返る」（通知時刻を過ぎたら出る）と、振り返りの通知
- 今日の集中時間・開けた時間と回数（ホームと同じ言葉。2026-10-03 からデトックスの時間の代わり。DTX-05、[digital-detox.md](digital-detox.md)）、カテゴリ別の時間（棒）
- **先週の自分との勝ち負け**（GHO-04、2026-10-02 オーナー決定）：集中・開けた時間・ポイントの3行（開けた時間は少ないほうが勝ち。2026-10-03）。各行に自分の値と先週の値、「勝ち」（前向きな色の札）・「負け」「引き分け」（落ち着いた色）。見出しの横に「今のところ・確定は朝4:00」（[ghost-race.md](ghost-race.md)「勝ち負け」）
- 目標との差（目標があるとき）。確定は朝4:00なので、夜の時点の途中経過
- 朝の計画（スナップショット）と実績のズレ：予定と15分以上（ちょうど15分を含む）ずれたブロックを、ズレの大きい順に最大2つ（Q19）。足りなかったものも超えたものも出す。例「予定 2時間 → 実際 0分　−2時間」
  - 対象は、振り返りを開いた時点で終わりの時刻を過ぎたブロックだけ（まだ来ていない夜のブロックはズレに数えない）
  - 実際の時間は、そのブロックから開始した記録の時間（一時停止を除く）。計画外で始めた記録は数えない（タイムラインの達成率と同じ数え方）
  - 日中に消したブロックも、朝の計画にあったので出る
  - 同じズレなら時刻の早い順。計画なし日は「今日は計画なしの日でした」、15分以上のズレがなければ「大きなズレはありませんでした」
- 先週の記録も目標もない日は、差の行を出さない。集中0分の日も同じ画面（0分と出す）
- 最後に「明日の計画を立てる」。押すと明日の計画画面（閉じられる、ボタンは「保存」）を開く。入れた内容は明日の1日の計画の下書きとして保存し、翌朝4:00以降に最初に開いたとき、朝の計画画面に入った状態で出る（翌朝の入力を軽くするため）
  - 「明日」は朝4:00区切りで今日の次の日（0:00〜3:59 に開いても、その夜の次の朝の日）
  - 明日の下書きがすでにあれば、それを開いて続きから直す
  - 最初のブロックの開始の初期値は、明日の 8:00（計画なし日の目標の始まりと同じ）
- 振り返りそのものは保存しない（DailyReview は作らない）。明日の計画の下書きは、ふだんの朝の計画の下書きと同じ形で保存する

## 週次（段階3）

- 予実のズレの集計（原因のメモは日次で取らないことにしたので、原因を扱うかは段階3で決める）

## 通知
- 振り返りの通知は毎日 22:00（初期値）。設定で時刻を変更できる
- 通知の許可は、初めて朝の計画を確定した直後に聞く（[focus-timer.md](focus-timer.md) TMR-05）。許可がないと届かない
- 通知を押すと、アプリが開いて振り返りが出る
- 文面は「今日を振り返りましょう」「今日の集中と、朝の計画とのズレを見返して、明日の計画を立てましょう。」（毎日同じ文面。その日の数字は入れられない）
- 時刻を変えたら、次からその時刻に出す（今日の分がまだなら今日から）
- ホームの「今日を振り返る」は、通知時刻から翌朝4:00まで出る。通知時刻を 0:00〜3:59 にしたら、その日の夜中（翌日の暦の 0:00〜3:59）から出る
