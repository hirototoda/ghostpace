# 振り返り

## 日次（夜）
段階1a（簡易）：数字だけの1枚（2026-10-01 決定。原因のメモは取らない。数字がしっかり見えればよい、とオーナー。[画面](../assets/2026-10-01-options-owner-ideas.png)）
- 入口：ホームの「今日を振り返る」（その日の区切りの時刻を過ぎたら出る。2026-10-21 からで、それまでは通知時刻を過ぎたら）と、振り返りの通知と、分析のタブの「今日の振り返り」（いつでも開ける。2026-10-05 オーナー決定、[analysis.md](analysis.md)）
- 今日の集中時間・開けた時間と回数（ホームと同じ言葉。2026-10-03 からデトックスの時間の代わり。DTX-05、[digital-detox.md](digital-detox.md)）、カテゴリ別の時間（棒）
- **先週の自分との勝ち負け**（GHO-04、2026-10-02 オーナー決定）：集中・開けた時間・ポイントの3行（開けた時間は少ないほうが勝ち。2026-10-03）。各行に自分の値と先週の値、「勝ち」（前向きな色の札）・「負け」「引き分け」（落ち着いた色）。その日の区切り（初期 22:00）の後に開いたときは確定した結果で、見出しの横には何も付けない（2026-10-21 オーナー決定。それまでは確定が朝4:00で、いつも「今のところ・確定は朝4:00」と出していた）。区切りより前に開いたとき（分析のタブから）だけ「今のところ・確定は22:00」（区切りの時刻）と出す（Claude 補足、Q47（非公開の判断表））（[ghost-race.md](ghost-race.md)「勝ち負け」）
- 目標との差（目標があるとき）。区切りの後は確定した差（区切りより前は途中経過）
- 朝の計画（スナップショット）と実績のズレ：予定と15分以上（ちょうど15分を含む）ずれたブロックを、ズレの大きい順に最大2つ（Q19）。足りなかったものも超えたものも出す。例「予定 2時間 → 実際 0分　−2時間」
  - 対象は、振り返りを開いた時点で終わりの時刻を過ぎたブロックだけ（まだ来ていない夜のブロックはズレに数えない）
  - 実際の時間は、そのブロックから開始した記録の時間（一時停止を除く）。計画外で始めた記録は数えない（タイムラインの達成率と同じ数え方）
  - 日中に消したブロックも、朝の計画にあったので出る
  - 同じズレなら時刻の早い順。計画なし日は「今日は計画なしの日でした」、15分以上のズレがなければ「大きなズレはありませんでした」
- 先週の記録も目標もない日は、差の行を出さない。集中0分の日も同じ画面（0分と出す）
- 最後に「明日の計画を立てる」。押すと明日の計画画面（閉じられる、ボタンは「保存」）を開く。入れた内容は明日の一日の計画の下書きとして保存する。区切りより後の予定（例 22:30〜23:30 の勉強）もここで入れ、区切りからはその下書きで動く（2026-10-21 オーナー決定、PLN-11、[daily-plan.md](daily-plan.md)「前の夜の予定」）。朝4:00以降に最初に開いたとき、朝の計画画面に入った状態で出る（翌朝の入力を軽くするため）
  - 「明日」は振り返っている日の次の日（区切り 22:00 なら、22:00 から始まる日。区切りの前に開いても後に開いても、0:00 を過ぎて開いても同じ日。2026-10-21 からで、それまでは朝4:00区切りで今日の次の日）。区切りの後は、もう始まっている日の下書きを直すことになるので、始まった・終わったブロックは動かせない（Claude 補足、Q47）
  - 明日の下書きがすでにあれば、それを開いて続きから直す
  - 最初のブロックの開始の初期値は、明日の 8:00（計画なし日の目標の始まりと同じ）
- 振り返りそのものは保存しない（DailyReview は作らない）。明日の計画の下書きは、ふだんの朝の計画の下書きと同じ形で保存する

## 通知
- 振り返りの通知は毎日、その日の区切りの時刻（初期 22:00、GHO-17）に出す（2026-10-21 オーナー決定。通知の時刻だけを変える設定はなくし、区切りの時刻の設定（[settings.md](settings.md)）に置き換えた。それまでは通知の時刻を別に設定でき、初期値 22:00）
- 通知の許可は、初めて朝の計画を確定した直後に聞く（[focus-timer.md](focus-timer.md) TMR-05）。許可がないと届かない
- 通知を押すと、アプリが開いて振り返り（確定したばかりの日）が出る
- 文面は「今日の結果が確定しました」「先週の自分との勝ち負けを見て、明日の計画を立てましょう。」（毎日同じ文面。その日の数字は入れられない。2026-10-21 オーナー決定の「今日の結果が確定しました」系で、本文は Claude 補足、Q47。それまでは「今日を振り返りましょう」「今日の集中と、朝の計画とのズレを見返して、明日の計画を立てましょう。」）
- 区切りの時刻を変えたら、通知も次の日の区切りから変わる（今日の分は今の区切りの時刻に出す。区切りと同じく次の日から効く。Claude 補足）
- 区切りに切り替えた版を最初に開いた日（その日はまだ朝4:00区切り）は、その日だけ 22:00 に今までの文面「今日を振り返りましょう」で出す（確定は朝4:00のままなので、振り返りの見出しは「今のところ・確定は朝4:00」）。前に予約してあった振り返りの通知（設定の通知の時刻）は取り消して予約し直す（Claude 補足、Q46（非公開の判断表）、[data-model.md](../../design/data-model.md)「第5版から移すとき」）
- ホームの「今日を振り返る」は、その日の区切りの時刻から、次の朝の計画を確定する（「今日は計画しない」を含む）まで出す。ただし遅くとも次の区切りまで（2026-10-21 オーナー決定で区切りの時刻から。終わりは Claude 補足、Q47。それまでは通知時刻から翌朝4:00まで）。区切りを夜中（0:00〜翌4:00）にしたら、その夜中から出る
