# タイムライン

## 目的
1日の計画と、実際にタイマーを動かした記録を同じ時間軸で見比べる。止め忘れた記録の終了時刻を直す場所でもある。

## 入口
下のタブの「分析」の一覧の「タイムライン」から進む（2026-10-05 から。それまでは下のタブの1つ。[analysis.md](analysis.md)）。

## 見た目（2026-10-01 決定：カード）
縦の時間軸・リスト・カードの3案を比べて、カードに決めた。[比較](../assets/2026-10-01-timeline-variants.png)（左から時間軸・リスト・カード）
- 計画ブロックごとに1枚のカード：名前、予定の時間帯、達成率（例：75%）
- 達成率＝そのブロックから始めた記録すべての、一時停止を除いた時間の合計 ÷ 今のブロックの長さ。実行中の記録は今までの分。ブロックの外まで続いた分・前倒しで早く始めた分（TMR-10）も入れるので100%を超えることがある。まだ始まっていないブロックで記録がなければ「—」
- カードの中の帯＝予定の時間帯。そのブロックから始めた記録の、実際に動かした部分を塗る（一時停止は薄く。帯は予定の範囲で切る）
- 帯の下に記録ごとの行：時刻・集中した時間・中断回数・「実行中」「修正済み」。直せる記録の行には「›」
- デトックスのブロックも同じ（青緑）

## 終了時刻を早める（TMR-08・TML-04）
- 記録の行をタップすると「終了時刻を早める」シートが出る。今日と昨日の記録だけ（2026-09-30 決定）。「今日・昨日」は記録を始めた日（朝4:00区切り）で決める。それより前の記録と実行中の記録は見るだけ（「›」を出さず、タップしても何も起きない）
- 選べるのは、開始の1分後から、今の終了時刻の1分前まで。延ばす・開始時刻を変える・消す・あとから足すことはできない。開始から2分未満の記録は直せない（選べる時刻がない）
- 一時停止の途中を選んだら、その一時停止の開始で終わったものとして扱う（focus-timer.md と同じ）。シートに「一時停止中なので ◯:◯◯ で終わります」と出す。その結果、長さが0になる場合（開始と同時に一時停止していた）は保存できない
- 元の終了時刻は、最初に直す前のものを残す（終了時の「いつやめましたか？」で直した記録も同じ。何度直しても上書きしない）
- 直した記録には「修正済み」と出す
- 直した結果が一時停止を除いて1分未満になっても、記録は消さない（終わった記録を操作で消さないため。終了時の「1分未満は記録しない」とは別）
- 保存するときにもう一度「今日・昨日の記録か」を確かめる（シートを開いたまま4:00を過ぎた場合など）。外れていたら保存せず知らせる
- 保存に失敗したら「保存できませんでした」を出し、シートは開いたまま。記録は変わらない
