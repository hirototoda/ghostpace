# デジタルデトックスの時間

## 目的
ゲームと SNS から離れていた時間を「デジタルデトックス」として数え、先週の自分と比べる。いつものブロック（[app-blocking.md](app-blocking.md)）が24時間効いているので、**ブロックが効いていた時間＝デトックス**とみなす（2026-10-01 オーナー決定、[ADR-0014](../../decisions/0014-detox-is-blocked-time.md)）。長押しで開けるほど減る。朝に決めた30分のゲーム・SNS の時間は、遊んでいてもデトックスとして数え続ける（不利益なく、決めた時間だけ遊べる。2026-10-01 オーナー決定）。

それまでは「デトックスのカテゴリ（掃除・運動・瞑想など）でタイマーを動かした時間」をデトックスとしていた。これを置き換える（切り替えるのは下の「切り替える場所」の PR③）。

**画面に出すのはデトックスの時間ではなく「開けた時間」**（2026-10-03 オーナー決定、[ADR-0018](../../decisions/0018-show-opened-time.md)）。デトックスの時間はほぼ「24時間 − 集中 − 開けた時間」になり、何もしなくても20時間前後まで増えるうえ、集中を頑張るほど減って勝ち負けが集中と食い違うため。デトックスの時間はポイント（DTX-03）の計算にだけ使う。下の「画面に出す数字（DTX-05）」。

## 数え方（DTX-01）
デトックスの時間 ＝ いつものブロックが実際に効いていた時間 から、集中のタイマー中を除いたもの。

| 数えない時間 | どう分かるか |
|---|---|
| ブロックを始める前、選択が読めなくなってから選び直すまで | 「始めた」「選択が読めなくなった」の記録 |
| Screen Time の許可が外れていた間 | 「許可が外れた／戻った」の記録。外れた時刻は分からないので、前に許可を確かめた時刻（GhostPace を最後に開いていた時刻）から外れていたとみなす（少なめに数える）。「外れた」から2分以内に「戻った」がある組は、iPhone が一瞬「未確認」と返したための誤記録とみなして数えない（2026-10-03 オーナー決定。過去の記録にも当てはめる） |
| 長押しで開けていた時間 | 「開けた」から「戻った」まで。合図が遅れて GhostPace を開いたときに戻したなら、その時刻まで（実際に開いていた時間） |
| ゲーム・SNS の時間を過ぎても開いていた分 | 予定の終わりから「ゲーム・SNS の時間で戻した」まで（合図が遅れて開いたままだった分）。予定どおりの30分はデトックスに数える |
| 集中のタイマー中（一時停止を除く） | タイマーの記録。集中として数えるので、二重に数えない |

- 数えない時間が重なっているときは、1回だけ除く（例：集中中に長押しで開けた15分は、デトックスに入らない。集中のタイマーの時間はそのままで、取り戻した時間・金額からは引く（Q24））
- **寝ている間も数える**。ポイントは1回の睡眠の最初の7時間が起きているときより高く、8時間を超えた分は0（睡眠を削っても得をしないように。下の「ポイント」）
- 集中のタイマーを一時停止している間は、デトックスに数える（いつものブロックが効いているため）
- デトックスのカテゴリ（家事・休み・運動と、自分で作ったもの）のタイマーは今までどおり使える。何をしていたかの記録としてタイムラインに出る。デトックスの時間は増えない（もう数えている）が、家事・運動・休みのタイマーは1日の上限までポイントが1.5倍になる（下の「ポイント」）
- 朝4:00で区切る（[ADR-0005](../../decisions/0005-day-boundary-4am.md)）。4:00 をまたぐ区間は、それぞれの日に分ける

例（ある日の 4:00〜翌 4:00。睡眠は前の夜 0:00〜7:00 と、その夜 0:00〜翌 7:00）
| 時間帯 | していたこと | デトックス |
|---|---|---|
| 4:00–7:00 | 寝ている | 3時間 |
| 7:00–9:00 | 起きている（ブロック中） | 2時間 |
| 9:00–12:00 | 勉強のタイマー（10:00–10:15 に長押しで開けた） | 0（集中のタイマーは3時間。開けた15分は取り戻した時間・金額に入れない、Q24） |
| 12:00–20:00 | ブロック中（料理のタイマー 30分を含む） | 8時間 |
| 20:00–20:30 | ゲーム・SNS の時間 | 30分（そのまま数える） |
| 20:30–24:00 | ブロック中 | 3時間30分 |
| 0:00–4:00 | 寝ている | 4時間 |
| **合計** | | **21時間** |

- 1日のデトックスは20時間前後になる。先週の自分との差がつくのは、長押しで開けた時間と集中の時間
- 集中が増えるとデトックスは減る。ポイントでは集中（10分＝1pt）のほうがデトックス（10分＝0.5pt）より高いので、集中して損はしない

## 睡眠（DTX-02）
睡眠の区間はポイントだけに使う。デトックスの時間は、寝ていても起きていても同じに数える。

- **どこに出すか**：朝の計画の上（日付の下）に「睡眠 0:10〜7:05　ヘルスケア」の行を出す。表示だけで、確かめる操作は求めない。違うと思ったときだけ押して、寝た時刻・起きた時刻を5分刻みで直す（起きた時刻は寝た時刻より後、長さは24時間未満）。計画のタブにも同じ行を出す（その日のうちは直せる）
- **中身**（その日の朝に終わった睡眠）：
  1. ヘルスケアの睡眠の記録（オーナーは Garmin で寝ていて、Garmin Connect がヘルスケアに書いている）。前の日の18:00〜その日の14:00（端末の時刻）に入っている睡眠のうち、1時間以上あかずに続いている一番長いまとまりの、最初から最後まで。長さが同じなら遅く終わった方。昼寝は数えない
  2. ヘルスケアに記録がなければ、設定の「睡眠の時刻」（初期 0:00〜7:00）を入れて「設定の時刻」と出す
- **書き込む時点**：その日の睡眠は、その日に初めて GhostPace を開いたとき（朝の計画の画面が出る・出ないにかかわらず）に、その時点の中身で保存する。朝の計画で「この計画で始める」を押したときにもヘルスケアを読み直し、ヘルスケアの値があればそこで決める（起きて計画を確定した時点では睡眠は終わっているため。2026-10-03）。それ以降に設定の時刻を変えても、保存した日の睡眠は変わらない。その日に一度も開かなかった日は、次に開いたときに設定の時刻で保存する
- **あとでヘルスケアに入ったら**（Garmin の同期が遅れた日など）：その日のうち（翌朝4:00まで）に GhostPace を開けば、ヘルスケアの値に置き換える。手で直していたら置き換えない。翌朝4:00を過ぎた日は置き換えない。計画を確定した後は、ヘルスケアの値で一度決まったら置き換えない（確定した時点でヘルスケアになかった日は、その日のうちに入ったときに1回だけ置き換え、そこで決まる）。「今日は計画しない」の日はこれまでどおり、その日のうちは新しい値に置き換える
- **どの時間が「寝ている」か**：ある日（4:00〜翌4:00）の中で、どの日の睡眠の区間に入っている時間も「寝ている」とする。例：その夜 0:00〜翌 7:00 の睡眠のうち 0:00〜4:00 はその日の時間。その区間は翌日の睡眠として翌朝決まるので、それまでは設定の時刻で仮に数え、翌朝決まったらその日のポイントを計算し直す（ポイントは勝ち負けに使わないため。デトックスの時間は変わらない）
- **手で読み直す**（2026-10-03 オーナー決定）：睡眠の行を押して開く「睡眠」の画面（寝た・起きたを直す画面）の保存の上に「ヘルスケアから読み直す」を出す（行の右に更新の印・計画の画面を下に引っぱる案と比べて選んだ。計画の画面に何も増やさないため）。押すと、上の「中身」の決まりでその日の睡眠をヘルスケアから読み直す
  - 記録があれば、計画を確定したあとでも・手で直していても、その値に置き換えて画面を閉じる（行は「ヘルスケア」になる。手で直していた日は、直す前の時刻も消え、長くした分を低めに数える決まりも外れる。手で直していた日に押したら置き換える、をオーナーが選んだ）。自分で押したときだけで、自動の読み直しの決まり（上の「あとでヘルスケアに入ったら」）は変わらない
  - 記録がなければ、今の時刻のまま「ヘルスケアに記録がありませんでした」と画面に出す（設定の時刻に戻す案と比べて選んだ）
  - 許可をまだ聞いていなければ、押したときに iPhone の許可の画面を出してから読む（Claude 補足）。ヘルスケアのない端末では出さない
  - 置き換えたあとで手で直すと、「直す前」はその読み直した値になる（Claude 補足）
  - 読み直せるのはその日の睡眠だけ（行に出ているのがその日の睡眠のため）。画面を開いたまま朝4:00を過ぎてから押したら、どの日も置き換えずに画面を閉じ、新しい日の睡眠を出す（Claude 補足）
  - 保存に失敗したら、手で直したときと同じく画面を閉じて「保存できませんでした」と知らせる（「記録がありませんでした」とは出さない。Claude 補足）
- **ヘルスケアの許可**：まだ聞いていないあいだは、睡眠の行の下と設定に「ヘルスケアから読む」を出し、押すと iPhone の許可の画面が出る（朝の計画に割り込んで聞かない。2026-10-02、操作の手数を増やさないため）。GhostPace はヘルスケアに書かない（読むだけ）。iPhone の仕組みで、許可を断ったのか記録がないだけなのかは GhostPace から分からない。どちらでも、記録がなければ設定の時刻を使う。許可を変えるのは iPhone の設定アプリ（ヘルスケア → データアクセスとデバイス → GhostPace）
- 寝ている間に長押しで開けた時間は、普通に除く

## ポイント（DTX-03）
1b のポイント（[ghost-race.md](ghost-race.md) GHO-14）のうち、集中以外の分の決まり。2026-10-03 に、やりすぎると1分の価値が下がり、開けるほど1回が重くなる形に作り直した（オーナー決定、[ADR-0019](../../decisions/0019-points-diminishing-returns.md)）。「続けたボーナス（×1.05 の複利）」はなくした。

1分ずつ、上の行から順に当てはまるもので数える。

| 状態（上が優先） | 10分あたり | 逓減 |
|---|---|---|
| ブロックが効いていない（長押しで開けた・ゲーム・SNS の時間を過ぎても開いていた・始める前・許可が外れた。集中中でも） | 0（デトックスの点） | — |
| 集中のタイマー中（一時停止を除く） | 集中のポイント（GHO-14。集中中に開けていた時間は上の行で0） | 集中の決まり |
| 家事・運動・休みのタイマー中 | 0.75pt（1.5倍） | 1日の上限まで。超えた分は0.5pt |
| 寝ている | 0.75pt | 1回の睡眠の最初の7時間まで。7〜8時間目は0.5pt、8時間を超えた分は0 |
| それ以外（起きていてブロック中） | 0.5pt | なし |

さらに、**長押しで開けたときに引く**：その日の n 回目に開けたとき、開けた時刻に n pt 引く（1回目1pt、2回目2pt、3回目3pt…。5回で合わせて15pt）。開けていた時間は上の表で0pt なので、長く開けるほど点も増えない。

### タイマーの上限（2026-10-03 オーナー決定）
| グループ | カテゴリ・ブロック | 1.5倍で数える上限（1日） |
|---|---|---|
| 家事 | 家事（ブロック名：掃除・料理・洗濯） | 1時間 |
| 運動 | 運動 | 3時間 |
| 休み | 休み（ブロック名：瞑想・休憩。集中の合間の休みをタイマーで計るときも） | 1時間 |
| なし | 自分で作って「なし」を選んだデトックスのカテゴリ | 上乗せなし（ブロック中と同じ0.5pt。記録として使う） |

- 上限はグループでまとめて数える（例：掃除40分と料理30分なら、料理の最後の10分は0.5pt）。朝4:00で0に戻る。その日の早い時刻のタイマーから順に上限を使う（Claude 補足）
- 「人と過ごす」（家族・友人・食事）のグループは候補。今は作らない（2026-10-03 オーナー決定）
- タイマーをずっと動かしておいても、ブロック中より多く取れるのは上限の分だけ（家事・休み +1.5pt、運動 +4.5pt）
- グループはカテゴリに保存する（2026-10-03 オーナー決定）。カテゴリを上限の単位、ブロック名を具体的にやることにする
- 自分でデトックスのカテゴリを作るときに、家事・運動・休み・なしから選ぶ。あとから設定のカテゴリの編集でも変えられる。点は毎回計算し直すので、変えると過去の点も新しいグループで数え直す（[settings.md](settings.md)）
- 掃除・料理・瞑想のカテゴリは、家事・休みのブロック名に組み替えた。過去の記録も付け替える（[settings.md](settings.md)「カテゴリの組み替え」）

### 睡眠の点（2026-10-03 オーナー決定）
- 「1回の睡眠」は、睡眠の区間（DTX-02）1つ。寝た時刻からの時間で数える（4:00 で日が変わっても続けて数える。例：0:00 に寝た睡眠の 4:00〜7:00 は、寝てから4〜7時間目なので0.75pt）
- 寝ている途中に開けたり集中のタイマーを動かしたりした時間も、寝てからの時間は進む（その時間は上の表で開けた・集中として数える。Claude 補足）
- 7時間で区切るのは、大人に勧められる睡眠が7〜9時間のため（米国睡眠財団、Hirshkowitz ら 2015, Sleep Health）。オーナーの感覚（7〜8時間）とも合う
- 睡眠を2時間短くすると −3pt（7時間まで0.75pt の時間が、起きてブロック中の0.5pt に変わる）。2時間長く寝ると −3pt（8時間を超えた1時間が0）。マイナスにはしない（寝不足の次の日の取り戻しや、体調の悪い日まで責めないため）
- 手で直した睡眠が直す前（ヘルスケア、なければ設定の時刻）より長いとき、長くした分は起きているときと同じ0.5pt にする（2026-10-03 オーナー決定。ヘルスケアがない日は設定の時刻と比べる案を選んだ。比べない案と比べた）。比べるのは**長さ**：寝た時刻から直す前の長さまでは寝ているとし、それを超えた分は「0.5pt」と「その時間の睡眠の点」の低いほうで数える（8時間目までは0.5pt、8時間を超えた分は0。ヘルスケアで長く記録された人より得をしないように。Claude 補足）
  - 例：直す前 0:00〜7:00（7時間）を 23:00〜8:00（9時間）に直した → 23:00〜6:00 は寝ている（31.5pt）、6:00〜7:00 は0.5pt、7:00〜8:00 は0（ヘルスケアに9時間と入った人と同じ 34.5pt）
  - 例：7時間で設定している人が実際は 0:00〜8:00 に寝た → 0:00〜8:00 の8時間の点は、ヘルスケアに入った場合（7時間まで31.5＋8時間目3.0）、入らずに設定の時刻のままの場合（睡眠31.5＋7:00〜8:00 のブロック中3.0）、手で8時間に直した場合（31.5＋長くした分3.0）のどれも 34.5pt（8時間寝て損をしない。2026-10-03 オーナーの質問から）
  - 例：直す前 5時間を8時間に直した → 5時間までは睡眠、長くした3時間は0.5pt（0.75pt の時間帯でも低いほうの0.5pt）
  - 第4版より前に手で直した日は、直す前の時刻が残っていないので比べず、直した時刻のまま数える（Claude 補足、Q33）
  - 例：設定の時刻 0:00〜7:00 の日に、実際の 1:00〜8:00 に直した → 長さは同じなので 1:00〜8:00 をそのまま寝ているとする（時刻で重なりを取ると、正しく直しただけで1.5pt 損をするため。2026-10-03 オーナーの質問から）
  - 短く直したときは直した時刻のまま
  - 「直す前」は最初に手で直す直前の値。何度直しても変わらない。手で直したあとにヘルスケアに入っても置き換えない（DTX-02）ので、比べる相手も変わらない
  - 朝の計画の上の睡眠の行は、今までどおり直した時刻を出す

### そのほか
- ゲーム・SNS の時間（予定の30分）は、上の表ではブロック中と同じに数える（0.5pt）。予定を過ぎても開いていた分は0pt だが、回数には入れないので引かない（開けた回数は長押しの回数。DTX-05）
- 朝4:00で0に戻る（ポイントも開けた回数も）
- 例：起きてから3時間、開けずにブロック中（タイマーなし）→ 180分×0.05＝9.0pt。途中で1回開けて10分戻らなかった → 170分×0.05−1＝7.5pt
- 小数1桁で出す（GHO-14 と同じ）
- 数字（上限・1pt の刻み）は仮の値。実機で数日使ってから見直す（Q25）

## 画面に出す数字：開けた時間（DTX-05）
2026-10-03 オーナー決定（[ADR-0018](../../decisions/0018-show-opened-time.md)）。ホームの小さい数字・夜の振り返り・先週の自分との勝ち負けで、デトックスの時間の代わりに出す。オーナーが決めたのは「数えるもの（長押し＋予定を過ぎた分。許可を外した時間は入れない）」「回数（長押しで開けた回数）」「0は『開けていない』」「ホームと振り返りで同じ形（案B）」「少ないほうが勝ち」「先週の記録が丸1日分ない日は記録なし」。「（Claude 補足）」の印があるものは画面で確かめてもらう（Q30（非公開の判断表））。

### 数え方
| 数えるもの | 中身 |
|---|---|
| 開けた時間 | 長押しで開けていた時間（「開けた」から「戻った」まで）と、ゲーム・SNS の時間を過ぎても開いていた分（予定の終わりから「ゲーム・SNS の時間で戻した」まで）。どちらも上の「数え方」で除く時間と同じ |
| 開けた回数 | 長押しで開けた回数（「開けた」の記録の数）。予定を過ぎて開いていた分は時間にだけ入り、回数には入れない |

- 朝に決めた30分のゲーム・SNS の時間は入れない（不利益なし。BLK-10）
- 集中のタイマー中に開けた分も入れる（重なっていても1回だけ数える）
- 入れないもの：ブロックを始める前、選択が読めなくなっていた間、Screen Time の許可が外れていた間（自分で開けたのではなく、外れた時刻も分からないため。デトックスの点は付かないので、そこで損はする）
- 朝4:00で区切る。4:00 をまたいで開けていた時間はそれぞれの日に分け、回数は開けた日に数える（Claude 補足）
- 寝ている間に開けた分も入れる（デトックスの「数え方」と同じ）
- 今開けている途中なら、今の時刻までを数える
- ゲーム・SNS の時間の終わりは iPhone のスケジュールで自動でブロックに戻るので、予定を過ぎて開いているのは合図が遅れた・届かなかったときだけ（次に GhostPace を開いたときに戻す）

### 見せ方
| その日の状態 | ホーム（円の下の小さい数字） | 夜の振り返り（今日の結果の「ゲーム・SNS」） |
|---|---|---|
| 開けた | 🔓 開けた **25分** ［2回］（回数は札。読み上げは「開けた 25分（2回）」） | 同じ |
| 予定を過ぎて開いていた分だけ | 🔓 開けた **5分**（札なし） | 同じ |
| 一度も開けていない | 🔒 **開けていない**（前向きな色） | 同じ |
| その日にブロックが一度も効いていない（始めていない・許可が外れていた。Claude 補足） | 出さない | 出さない |

### 先週の自分との勝ち負け
- 「開けた時間」の行。**少ないほうが勝ち**。比べるのは振り返りを開いた時刻まで（先週も同じ時刻まで）
- 時間は分（1分未満は切り捨て）でそろえ、同じなら引き分け（「1分未満」同士も引き分け）。回数は添えるだけで勝ち負けには使わない（Claude 補足。ほかの行と同じ細かさにそろえるため）
- 先週のブロックの記録が丸1日分ない日は「先週の記録なし」（何もしなくても0分で勝ててしまうため。今までのデトックスの行と同じ）。先週のその日にブロックが一度も効いていなかったとき（許可が外れていた等）も同じ（Claude 補足）
- 今日ブロックが一度も効いていない日は、開けた時間の行を出さない（集中とポイントの2行になる。Claude 補足）
