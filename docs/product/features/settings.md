### 通知
| 行 | 内容 |
|---|---|
| 振り返りの通知 | 時刻（初期値 22:00、REV-02）。ホームの「今日を振り返る」もこの時刻から出る |
| 予定の時間の通知 | オン／オフ（初期値オン、TMR-05）。計画外のタイマー中に次の計画の時刻が来たときの通知（TMR-11）も、これに従う |
| 計画の前の通知 | オフ・ちょうど・5分前・10分前・15分前（初期値5分前、TMR-12、2026-10-04）。計画ブロックが始まる前に「まもなく英語」と知らせる（[focus-timer.md](focus-timer.md)） |

- 通知は iPhone の許可がないと届かない。許可がないときは通知の欄の上に「通知はまだオフです　オンにする」（まだ聞いていない）か「iPhone の設定アプリで通知を許可してください　設定を開く」（断った）を出す（[focus-timer.md](focus-timer.md)）

### 睡眠（DTX-02、2026-10-01）
| 行 | 内容 |
|---|---|
| 睡眠の時刻 | 寝る・起きる時刻（初期 0:00〜7:00、5分刻み）。ヘルスケアに睡眠の記録がない日に使う |

### カテゴリ
- 「集中に数える」「デジタルデトックス」の2つに分けて並べる（2026-10-01 決定。1つの一覧にスイッチを並べる案と比べて選んだ。うっかり数え方を変えないため）
- 行にはカテゴリ名と、ブロック名の数（あれば）。デトックスの欄は右に小さくグループ（「家事」「なし」など、2026-10-03 オーナー決定）。押すとカテゴリの編集を開く
- 最後に「＋ カテゴリを追加」と「アーカイブしたもの」
- 「ゲーム・SNS」（BLK-10）はカテゴリではないので、この一覧には出ない（計画のブロックの種類。[daily-plan.md](daily-plan.md)）

### カテゴリの編集
- デトックスのカテゴリは、グループ（家事・運動・休み・なし）を変えられる（2026-10-03 オーナー決定）。追加と同じ一覧。下に「グループを変えると、これまでの点も新しいグループで数え直します。」と出す（集中／デトックスの切り替えは、これから始める記録から効くのと違うため）
- 集中に切り替えるとグループは消え、デトックスに切り替えると「なし」から始まる（Claude 補足、Q33）
| 項目 | 内容 |
|---|---|
| 名前 | 変えられる。空にはできない。ほかのカテゴリ（アーカイブ以外）と同じ名前にはできない（理由を出す） |
| 数え方 | 集中／デトックス（CAT-02）。変えると、これから始める記録から効く。これまでの記録はそのまま（2026-09-30 決定） |
| ブロック名 | そのカテゴリのブロック名の一覧。名前の変更、左にスワイプでアーカイブ、「＋ ブロック名を追加」（CAT-03） |
| アーカイブ | 「このカテゴリをアーカイブ」。記録は消えず、選ぶ一覧に出なくなる。「アーカイブしたもの」から戻せる。最後の1つはアーカイブできない。実行中のタイマーのカテゴリをアーカイブ・数え方を変えても、そのタイマーの記録は開始したときのまま |

### カテゴリを追加（CAT-04）
- 名前と、集中／デトックスを選ぶ。初期値は集中
- デトックスなら、グループ（家事・運動・休み・なし）も選ぶ。初期値は「なし」（Claude 補足、Q33）。1行ずつに上限（「1日1時間まで1.5倍」など）を書いた一覧で、選んだ行に印（2026-10-03 オーナー決定。切り替えボタン・メニューと比べた、[画面](../assets/2026-10-03-options-detox-group.png)）。家事・運動・休みは1日の上限まで1.5倍（[digital-detox.md](digital-detox.md)「タイマーの上限」）。上限はグループでまとめて数えるので、カテゴリを増やしても上限は増えない
- 同じ名前のカテゴリ（アーカイブ以外）があれば作らず、そのカテゴリを使う（ブロック名と同じ決まり）
- 設定のほか、ブロックを追加・計画外で開始の画面の、カテゴリ一覧の最後の「＋ カテゴリ」からも同じ画面を開く

## デフォルトのカテゴリ
勉強・仕事・読書（集中）、家事（ブロック名：掃除・料理・洗濯）・休み（瞑想・休憩）・運動（デトックス）（CAT-01、2026-10-03）。グループは家事＝家事、休み＝休み、運動＝運動。

それまでは掃除・休み・料理・運動・瞑想（デトックス）だった。瞑想は 2026-10-01 に追加し、すでに使っている端末にも1回だけ足した（足したかどうかは端末の設定に覚えている）。

### カテゴリの組み替え（2026-10-03 オーナー決定）
**結果**：掃除・料理は「家事」のブロック名、瞑想は「休み」のブロック名になり、過去の記録もそこに移る。

すでに使っている端末では、次に起動したときに1回だけ組み替える。オーナーが決めたのは「掃除・料理・瞑想をブロック名にする」「過去の記録・計画・テンプレートも付け替える」「朝の計画の写しは変えない」。細かい分かれ道は Claude 補足（Q33（非公開の判断表））。

| 場合 | どうするか |
|---|---|
| ふつう（掃除・料理・瞑想がデトックスのまま） | 掃除の名前を「家事」に変える。料理・瞑想はアーカイブし、記録を家事・休みに移す |
| すでにデトックスの「家事」がある | その家事を使い、掃除もアーカイブして記録を家事に移す |
| 「掃除」がアーカイブ済みで、家事もない | 家事を新しく作り、アーカイブした掃除の記録を移す |
| 「休み」がない | 瞑想があれば休みを新しく作る |
| 掃除・料理・瞑想がどれもない | 何もしない（家事・休みは作らない） |
| 掃除・料理・瞑想を集中に切り替えていた | 組み替えない（集中の記録をデトックスに移さないため） |
| 「家事」「休み」という名前の集中のカテゴリがある | 名前が重なるので組み替えず、掃除・料理に家事、瞑想に休みのグループだけ付ける |
| 名前を変えていた（例：掃除→片付け） | 名前で探すので組み替えない（移すものがなければ家事も作らない）。グループは「なし」になるので、設定で選び直す |

- ブロック名：家事に掃除・料理・洗濯、休みに瞑想・休憩を用意する。同じ名前（アーカイブ済みも）があればそれを使い、アーカイブなら戻す。もとのカテゴリの中にあったブロック名は行き先に移し、同じ名前があればそちらにまとめる
- 付け替えるもの：タイマーの記録（実行中・一時停止中も。開始時刻と一時停止は変えない）、計画のブロック（確定済み・下書き・明日の下書き・消した印のもの）、テンプレート。ブロック名がなかったものは、もとのカテゴリ名のブロック名（掃除・料理・瞑想）にする
- 変えないもの：朝に確定した計画の写し（PLN-03。アーカイブしたカテゴリも名前で読めるので、振り返りはそのまま）、記録に写した集中かどうか（どれもデトックスのまま）
- グループ：家事＝家事、休み＝休み、運動＝運動。それまで名前でグループを決めていた「洗濯」（家事）・「休憩」（休み）という名前のデトックスのカテゴリにも同じグループを付ける（組み替えで点が下がらないように）。ほかのデトックスのカテゴリは「なし」
- 1回の保存でまとめて行い、成功したら端末の設定に「組み替えた」を覚える。途中で失敗したら何も変えず、次の起動でやり直す。もう一度通しても結果は同じ
- 新しく入れた端末は新しいデフォルトで始め、組み替えを1回通して（何も変わらない）覚える
- 瞑想を1回だけ足す処理（2026-10-01）はやめ、この組み替えにまとめる（足したあとに組み替えると瞑想のカテゴリが戻ってしまうため）
- 点は毎回計算するので、過去の点も新しいグループで数え直す

## 端末の設定に保存するもの
記録（SwiftData）とは別に、端末の設定（UserDefaults）に置く。アプリを消すと消える（記録と同じ）。
| 項目 | 初期値 |
|---|---|
| 振り返りの通知の時刻 | 22:00 |
| 予定の時間の通知 | オン |
| 通知の説明を出したか | まだ |
| 瞑想を足したか（2026-10-03 から使わない） | まだ |
| カテゴリを組み替えたか（2026-10-03） | まだ |
| ホームで選んだ対戦相手 | 先週の自分 |
| ブロックの説明を出したか | まだ |
| 睡眠の時刻 | 0:00〜7:00 |
| ヘルスケアの説明を出したか | まだ |

ブロックの対象・開けている期限・ブロックの記録は、端末の設定とは別に、シールドなどの部品と GhostPace の両方から読める置き場に置く（[data-model.md](../../design/data-model.md)）。

同じ名前のカテゴリは作らない・同じ名前に変えられない、アーカイブから戻せる、最後の1つはアーカイブできない（2026-10-01 オーナー確認）。
