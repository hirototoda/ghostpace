# 分析

## 目的
過去の自分の数字をまとめて見返す場所。タイムライン・ポイントの推移・夜の振り返りを1つのタブにまとめ、そこから進む（2026-10-05 オーナー決定。タイムラインはすぐ見られる必要はないので、分析としてひとまとめにした）。

## 入口（NAV-01）
下のタブの3つ目を「タイムライン」から「分析」に置き換える（4つ目のタブとして足す案と比べた）。中は項目の一覧で、押すとそれぞれの画面に進む（小さな概要のカードを並べる案と比べた）。[画面](../assets/2026-10-05-analysis-hub-day.png)

| 項目 | 進む先 | 行の下の小さい文字（Claude 補足） |
|---|---|---|
| ポイントの推移 | 下の「ポイントの推移」 | 「7日の平均 96.5pt」（昨日までの7日のうち、記録のある日の平均。今日は途中なので入れない）。記録のある日がなければ出さない |
| タイムライン | 今までのタイムライン（[timeline.md](timeline.md)）。中身は変えない | 「今日の集中 3時間55分」 |
| 今日の振り返り | 夜の振り返り（[review.md](review.md)）を同じ形で開く | 「先週の自分との勝ち負けと、朝の計画とのズレ」 |

- 今日の振り返りは、分析からならいつでも開ける（2026-10-05 オーナー決定。通知の時刻からにする案と比べた）。中身はその時刻までの「今のところ」。ホームの「今日を振り返る」は今までどおり通知の時刻から出す
- 分析のタブで進んだ先は、ほかのタブへ行って戻っても残る（Claude 補足）

## ポイントの推移（ANA-04）
日ごとの1日の合計ポイント（GHO-14。集中＋デトックス）を、先週の同じ曜日と比べて見る。

- **グラフ**：折れ線（2026-10-05 オーナー決定。棒と比べて選んだ、[案の比較](../assets/2026-10-05-options-points-history.png)）。自分は実線と点、先週の同じ曜日は点線。縦は見えている値に合わせる（ホームの裏のグラフと同じ決まり。0から始めないので差が見える）
- **期間**：上の［7日｜30日］で切り替える。初めは7日。右の端が今日（Claude 補足）
- **今日**：今の時刻までの値で、先週の同じ曜日も同じ時刻まで（ホームの裏のグラフの上の行と同じ数字）。まだ途中なので、前の日から今日への線と今日の点は薄い色にする（途中の値で線が大きく下がって見えるため。Claude 補足）。下に「今日は今まで（薄い色）」
- **日ごと**：グラフの下に新しい日から1日ずつの行。日付、その日の合計、「先週より +4.1pt」（前なら前向きな色、後ろなら落ち着いた色。ホームの差と同じ丸め）。押すとその日のグラフ（ANA-05）
- **記録なしの日**：タイマーの記録・計画（下書き・確定・計画なし）・保存した睡眠のどれもない日は「記録なし」と出し、グラフにも点を置かない。押せない。使い始める前の日などに、設定の睡眠の時刻だけで点が付くのを防ぐため（Claude 補足）
- **先週と比べられない日**：先週の同じ曜日に丸1日分のブロックの記録がない日は、点線と「先週より」を出さない（ホームの裏のグラフで相手の線を出さないのと同じ）

## その日のグラフ（ANA-05）
ホームの円の裏と同じグラフ（[ghost-race.md](ghost-race.md) GHO-13）で、その日の自分と相手の線を見る。[画面](../assets/2026-10-05-analysis-hub-day.png)
- 相手はホームで今選んでいる相手（先週の自分・目標）。その日にその相手がいなければ自分の線だけ（Claude 補足）
- 過ぎた日は 4:00〜翌4:00 の1日で始め、開いたときの動きはない。上の行は「この日 95.1pt」と相手の値・差（その日の終わり＝翌4:00 の値）。「今」の縦線は引かない。［3時間］で 翌1:00〜翌4:00 から横にずらせ、［▶］でその日を流せる（1日分で約25秒）（Claude 補足）
- 今日を押したときは、ホームの裏と同じ（今のまわりの3時間、開いたときの動き）
- 画面の上の見出しはその日の日付（例「10月18日(日)」）

## 数え方（Claude 補足）
- 過去の日のポイントは、ホームと同じ計算をその日の記録で毎回やり直す（保存しない）。あとからカテゴリのグループを変えたり記録を直したりすると、過去の数字も変わる（Q33（非公開の判断表）と同じ考え）
- その日の睡眠が保存されていない日は、今の設定の時刻で数える（ホームの「前の日」の扱いと同じ）
- 日付の区切りは朝4:00。0:00〜3:59 に開くと前の日が「今日」

## 有料との関係
有料の範囲（PAY-02：分析と先週より前の履歴）は、課金（公開の準備）を入れるときに決める。それまでは全部見られる。
