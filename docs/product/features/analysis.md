# 分析

## 目的
過去の自分の数字をまとめて見返す場所。タイムライン・ポイントの推移・夜の振り返りを1つのタブにまとめ、そこから進む（2026-10-05 オーナー決定。タイムラインはすぐ見られる必要はないので、分析としてひとまとめにした）。

## 入口（NAV-01）
下のタブの3つ目を「タイムライン」から「分析」に置き換える（4つ目のタブとして足す案と比べた）。中は項目の一覧で、押すとそれぞれの画面に進む（小さな概要のカードを並べる案と比べた）。[画面](../assets/2026-10-05-analysis-hub-day.png)

| 項目 | 進む先 | 行の下の小さい文字（Claude 補足） |
|---|---|---|
| ポイントの推移 | 下の「ポイントの推移」 | 「7日の平均 96.5pt」（昨日までの7日のうち、記録のある日の平均。今日は途中なので入れない）。記録のある日がなければ出さない |
| タイムライン | 今までのタイムライン（[timeline.md](timeline.md)）。中身は変えない | 「今日の集中 3時間55分」 |
| 今日の振り返り | 夜の振り返り（[review.md](review.md)）を同じ形で開く | 「先週の自分との勝ち負けと、朝の計画とのズレ」 |
| 自己ベスト | 下の「自己ベスト」 | 「集中 6時間10分（9月28日）」（2026-10-06） |
| 時間帯の地図 | 下の「時間帯の地図」 | 「よく集中するのは 水曜の 10:00–12:00」（2026-10-06） |

- 今日の振り返りは、分析からならいつでも開ける（2026-10-05 オーナー決定。通知の時刻からにする案と比べた）。中身はその時刻までの「今のところ」。ホームの「今日を振り返る」は今までどおり通知の時刻から出す
- 分析のタブで進んだ先は、ほかのタブへ行って戻っても残る（Claude 補足）

## ポイントの推移（ANA-04）
日ごとの1日の合計ポイント（GHO-14。集中＋デトックス）を、先週の同じ曜日と比べて見る。

- **グラフ**：折れ線（2026-10-05 オーナー決定。棒と比べて選んだ、[案の比較](../assets/2026-10-05-options-points-history.png)）。自分は実線と点、先週の同じ曜日は点線。縦は見えている値に合わせる（ホームの裏のグラフと同じ決まり。0から始めないので差が見える）
- **期間**：上の［7日｜30日］で切り替える（オーナーが選んだ案の説明に入れていた）。初めは7日・右の端が今日（Claude 補足）
- **さかのぼる**（2026-10-06 オーナー決定。グラフを横にずらす案と比べた）：［7日｜30日］の下に「‹ 9月23日〜9月29日 ›」。‹ で1期間（7日なら7日、30日なら30日）前へ、› で新しいほうへ戻る。日ごとの行も見ている期間の日に変わる
  - 初めは今日が右の端で、› は押せない。‹ は一番古いタイマーの記録の日を含む期間まで（それより前は全部「記録なし」なので。日数の上限はない。Claude 補足）
  - ［7日｜30日］を切り替えると、今日が右の端の期間に戻る（Claude 補足）
  - 今日を含まない期間では、薄い線と「今日は今まで（薄い色）」を出さない（Claude 補足）
- **今日**：今の時刻までの値で、先週の同じ曜日も同じ時刻まで（ホームの裏のグラフの上の行と同じ数字）。まだ途中なので、前の日から今日への線と今日の点は薄い色にする（途中の値で線が大きく下がって見えるため。Claude 補足）。下に「今日は今まで（薄い色）」
- **日ごと**（Claude 補足）：グラフの下に新しい日から1日ずつの行。日付、その日の合計、「先週より +4.1pt」（前なら前向きな色、後ろなら落ち着いた色。ホームの差と同じ丸め）。押すとその日のグラフ（ANA-05）
- **記録なしの日**：タイマーの記録・計画（下書き・確定・計画なし）・ブロックが効いていた時間のどれもない日は「記録なし」と出し、グラフにも点を置かない。押せない。使い始める前の日などに、設定の睡眠の時刻だけで点が付くのを防ぐため。ブロックが効いていたかは、開けた時間を出すかどうか（DTX-05）と同じ判定（Claude 補足）
- **先週と比べられない日**：先週の同じ曜日に丸1日分のブロックの記録がない日は、点線と「先週より」を出さない（ホームの裏のグラフで相手の線を出さないのと同じ）

## その日のグラフ（ANA-05）
ホームの円の裏と同じグラフ（[ghost-race.md](ghost-race.md) GHO-13）で、その日の自分と相手の線を見る。[画面](../assets/2026-10-05-analysis-hub-day.png)
- 相手はホームで今選んでいる相手（先週の自分・目標）。その日にその相手がいなければ自分の線だけ（Claude 補足）
- 過ぎた日は 4:00〜翌4:00 の1日で始め、開いたときの動きはない。上の行は「この日 95.1pt」と相手の値・差（その日の終わり＝翌4:00 の値）。「今」の縦線は引かない。［3時間］で 翌1:00〜翌4:00 から横にずらせ、［▶］でその日を流せる（1日分で約25秒）（Claude 補足）
- 今日を押したときは、ホームの裏と同じ（今のまわりの3時間、開いたときの動き）
- 画面の上の見出しはその日の日付（例「10月18日(日)」）

- **ラップの一覧**（GHO-06、2026-10-06）：グラフの下に2時間ごとの区間を並べ、区間ごとの自分・相手の集中と差（「10:00–12:00 1時間20分・先週 1時間08分 +12分」）。今日は今の区間まで。自分も相手も集中していない区間は省く（Claude 補足、Q39）

細部の Claude 補足は Q35（非公開の判断表）でオーナーに確かめる。

## 自己ベスト（ANA-06、2026-10-04・10-06 オーナー決定）
- 一番多い1日の「集中した時間」と「ポイント」を、その日の日付と一緒に出す。押すとその日のグラフ（ANA-05）
- 今日は途中なので入れない（今日とは下の「今日と比べる」とラップ表で比べる。ホームの「あと30分で自己ベスト」も今日と比べる。GHO-15）
- 申告した時間も集中した時間に入る（TMR-13）。数えるのは記録のある日だけ（ポイントの推移の「記録なし」と同じ判定。Claude 補足、Q39）

### 期間（2026-10-06 オーナー決定）
- 上の［全期間｜今月｜今週］で切り替える。初めは全期間。開き直すと全期間に戻る（Claude 補足）
- 全期間は使い始めの日から全部（日数の上限はない。Claude 補足）
- 週は月曜から日曜（日曜始まりと比べた）、月は1日から末日。どちらも朝4:00で日付を区切る（月曜の 0:00〜3:59 はまだ日曜で、前の週）
- 今日は入れない（今日も途中の値で入れる案と比べた）。期間の中に記録のある日がなければ「今週はまだ記録なし（今日が終わると入ります）」とだけ出し、下の「今日と比べる」とラップ表は出さない（比べるベストの日がないため。月曜の今週・1日の今月は必ずこうなる。Claude 補足）
- ポイントが同じ日が2つあれば新しい日をベストにする（集中した時間のベストと同じ。Claude 補足）

### 今日と比べる（2026-10-06 オーナー決定）
- ベストの下に「今日」の行：今日の今までのポイントと、選んでいる期間のポイントのベストの日の同じ時刻（4:00 からの経過で揃える）までのポイント、その差。今日が上回っていれば今日の値と差を赤にする（ラップ表と同じ赤。Claude 補足）

### ラップ表（2026-10-06 オーナー決定）
選んでいる期間のポイントのベストの日と、今日を2時間ごとに比べる表。[画面](../assets/2026-10-06-best-laps.png)

```
          今日            ベストの日         差
区間      区間    累計     区間    累計      累計
 6:00      9.1    18.1      7.5    16.5     +1.6
 8:00      9.5    27.6      9.5    26.0     +1.6
  …
14:00      2.0    43.4      6.0    48.5     −5.1
 途中
16:00       —       —       8.8    59.2       —
```

- 縦は2時間の区間（ラップと同じ12区間、4:00–6:00 … 翌2:00–翌4:00）を始まりの時刻（「8:00」）で書く。横は5列で、すべてポイント（オーナーの案。区間ごとにベストの日と今日の2行を重ねる案・差の行を足す案と比べた）
- 見出しは2段：上に「今日」「ベストの日」「差」、下に「区間」「累計」（2026-10-06 オーナー決定。1段の「区間｜今日｜累計｜ベスト｜累計｜差」と比べた）
- 「区間」はその区間で増えたポイント、「累計」はその区間の終わり（今の区間は今）までにたまったポイント。その日のグラフ（GHO-13）と同じ数え方で、集中・デトックス・睡眠・計画どおりの点のすべてが、付いた時刻の区間に入る（夜の睡眠の点は夜の区間に入る）。なので最後の累計はその日の合計（ポイントの推移の値）と同じ。開けた時間でポイントが減った区間はマイナスで出す（Claude 補足）
- **赤**：今日がベストの日を上回った数字を赤にする（区間・累計のそれぞれ）。累計の差は今日が前なら赤（+）、後ろなら落ち着いた色。比べるのは画面に出す小数1桁の値で、同じに見えるなら色を付けない。差も画面に出す2つの値の引き算にする（12.0 と 12.0 なら 0.0。別々に丸めて「+0.1」と出ないように）（Claude 補足）。ここの赤は「勝っている」の印（陸上の速報で記録を赤く出すのと同じ）で、負けには使わない。ほかの画面の差の色（前向きな色）は変えない
- 今の区間は下に「途中」と出し、ベストの日も同じ時刻までの値で比べる（Claude 補足）
- まだ来ていない区間は今日の欄を「—」にする。ベストの日の欄は出す（この先のベストの日のペースが見える。Claude 補足）
- 区間の値が今日もベストの日も 0.0 の区間は省く（まだ来ていない区間は今日を0とみなす。その日のラップの一覧と同じ。Claude 補足）
- 集中した時間は入れない（2026-10-06 オーナー決定。区間の下に小さく出す案・列を足す案と比べた）。区間ごとの集中は、ベストの日を押して開くその日のグラフのラップ（GHO-06）で見られる
- 文字サイズを標準の最大（設定の目盛りのいちばん右）か、それより大きくしているときは、5列が入らないので区間ごとに縦に並べる。「今日 9.1 ／ 今日の累計 18.1 ／ ベストの日 7.5 ／ ベストの日の累計 16.5 ／ 累計の差 +1.6」を1行ずつ（Claude 補足）
- 開いている間も1分ごとに数え直す（タイマーが動いていれば今の区間が進む。4:00 を過ぎれば新しい今日で比べ直す。ほかの分析の画面と同じ。Claude 補足）

細部の Claude 補足は Q41（非公開の判断表）でオーナーに確かめる。

## 時間帯の地図（ANA-07、2026-10-04・10-06 オーナー決定）
- 曜日（月〜日）×2時間の区間（ラップと同じ12区間）のマス。色の濃さは、その曜日・区間に集中した時間の平均（直近4週。今日は入れない）。濃いほど集中している
- 下に「よく集中するのは 水曜の 10:00–12:00」（一番濃いマス）と色の目安
- 4週に満たないときは、ある分だけで平均する（記録のない日は0として数えない。Claude 補足、Q39）

## 数え方（Claude 補足）
- 過去の日のポイントは、ホームと同じ計算をその日の記録で毎回やり直す（保存しない）。あとからカテゴリのグループを変えたり記録を直したりすると、過去の数字も変わる（Q33（非公開の判断表）と同じ考え）
- その日の睡眠が保存されていない日は、今の設定の時刻で数える（ホームの「前の日」の扱いと同じ）
- 日付の区切りは朝4:00。0:00〜3:59 に開くと前の日が「今日」
