## ポイントの推移（ANA-04）
日ごとの1日の合計ポイント（GHO-14。集中＋デトックス）を、先週の同じ曜日と比べて見る。

- **グラフ**：折れ線（2026-10-05 オーナー決定。棒と比べて選んだ、[案の比較](../assets/2026-10-05-options-points-history.png)）。自分は実線と点、先週の同じ曜日は点線。縦は見えている値に合わせる（ホームの裏のグラフと同じ決まり。0から始めないので差が見える）
- **期間**：上の［7日｜30日］で切り替える（オーナーが選んだ案の説明に入れていた）。初めは7日・右の端が今日（Claude 補足）
- **さかのぼる**（2026-10-06 オーナー決定。グラフを横にずらす案と比べた）：［7日｜30日］の下に「‹ 9月23日〜9月29日 ›」。‹ で1期間（7日なら7日、30日なら30日）前へ、› で新しいほうへ戻る。日ごとの行も見ている期間の日に変わる
  - 初めは今日が右の端で、› は押せない。‹ は一番古いタイマーの記録の日を含む期間まで（それより前は全部「記録なし」なので。日数の上限はない。Claude 補足）
  - ［7日｜30日］を切り替えると、今日が右の端の期間に戻る（Claude 補足）
  - 今日を含まない期間では、薄い線と「今日は今まで（薄い色）」を出さない（Claude 補足）
- **今日**：今の時刻までの値で、先週の同じ曜日も同じ時刻まで（ホームの裏のグラフの上の行と同じ数字）。まだ途中なので、前の日から今日への線と今日の点は薄い色にする（途中の値で線が大きく下がって見えるため。Claude 補足）。下に「今日は今まで（薄い色）」
- **日ごと**（Claude 補足）：グラフの下に新しい日から1日ずつの行。日付、その日の合計、「先週より +4.1pt」（前なら前向きな色、後ろなら落ち着いた色。ホームの差と同じ丸め）。押すとその日のグラフ（ANA-05）
- **ベストの印**（ANA-08、2026-10-07 オーナー決定。陸上の PB・SB から）：日ごとの行の日付の横に「自己ベスト」「月間ベスト」「週間ベスト」の小さな印。今その記録を持っている日に付ける（塗り替えた日に残す案と比べた）
  - 週間ベストは月曜〜日曜の週ごとに一番ポイントの多い日、月間ベストは月ごと、自己ベストは全体で一番の日。前の週・月にさかのぼっても、その週・月の一番の日に付く
  - 1日に重なれば上の印だけ（自己ベスト＞月間ベスト＞週間ベスト）。今日は終わるまで付けない。同じポイントなら新しい日（自己ベストと同じ決まり。Claude 補足）
  - 今日が超えたときの知らせは下の「ホームの帯」
- **記録なしの日**：タイマーの記録・計画（下書き・確定・計画なし）・ブロックが効いていた時間のどれもない日は「記録なし」と出し、グラフにも点を置かない。押せない。使い始める前の日などに、設定の睡眠の時刻だけで点が付くのを防ぐため。ブロックが効いていたかは、開けた時間を出すかどうか（DTX-05）と同じ判定（Claude 補足）
- **先週と比べられない日**：先週の同じ曜日に丸1日分のブロックの記録がない日は、点線と「先週より」を出さない（ホームの裏のグラフで相手の線を出さないのと同じ）

### 期間（2026-10-06 オーナー決定）
- 上の［全期間｜今月｜今週］で切り替える。初めは全期間。開き直すと全期間に戻る（Claude 補足）
- 全期間は使い始めの日から全部（日数の上限はない。Claude 補足）
- 週は月曜から日曜（日曜始まりと比べた）、月は1日から末日。どちらも朝4:00で日付を区切る（月曜の 0:00〜3:59 はまだ日曜で、前の週）
- 今日は入れない（今日も途中の値で入れる案と比べた）。期間の中に記録のある日がなければ「今週はまだ記録なし（今日が終わると入ります）」とだけ出し、下の「今日と比べる」とラップ表は出さない（比べるベストの日がないため。月曜の今週・1日の今月は必ずこうなる。Claude 補足）
- ポイントが同じ日が2つあれば新しい日をベストにする（集中した時間のベストと同じ。Claude 補足）

### 今日と比べる（2026-10-06 オーナー決定）

### ラップ表（2026-10-06 オーナー決定）
選んでいる期間のポイントのベストの日と、今日を2時間ごとに比べる表。[画面](../assets/2026-10-06-best-laps.png)

**比べる相手**（2026-10-07 オーナー決定。平均の列を足す案・平均との差の列だけ足す案と比べた）：「今日と比べる」の一番上の［ベストの日｜平均｜区間ベスト］で切り替える（2026-10-07 オーナーが画面の案から選んだ。表の見出しのメニューにする案と比べた）。下の「今日と比べる」の行とラップ表の両方に効く。どれも上の［全期間｜今月｜今週］の期間の、記録のある日（ポイントの推移の「記録なし」でない日。今日は入れない）から作る。表の形（5列・見出し2段・赤の決まり）は相手が変わっても同じで、見出しの「ベストの日」が相手の名前に変わる。上の「今日と比べる」の行も選んだ相手と比べる（「平均の同じ時刻 48.5pt」。Claude 補足）
- 初めはベストの日。期間を変えても、ほかのタブへ行って戻っても選んだ相手のまま。自己ベストの画面を閉じて開き直すとベストの日に戻る（期間と同じ。Claude 補足）
- 期間に記録のある日がなければ、相手の切り替えも表も出さない（上の「期間」と同じ）
- **平均**（2026-10-07 オーナー決定。直近4週の同じ曜日・直近7日の案と比べた）：期間の記録のある日の、その時刻までのポイントの平均。区間は平均の累計どうしの差で、最後の累計は期間の1日の平均（ポイントの推移の行の「7日の平均」と数え方は同じで、日の範囲が違う）。見出しは「平均（12日）」のように日数を添える。1日しかなければその日の値で「平均（1日）」（Claude 補足）
- **区間ベスト**：下の「区間ベストと理論ベスト」でつないだ1日。起きている区間は区間ベストの日の値（1日の合計の決まりで数え直した値）、睡眠の区間は平均。最後の累計が理論ベスト。今の区間は、区間全体の値で選んだ日の同じ時刻までの値（Claude 補足）

```
          今日            ベストの日         差
区間      区間    累計     区間    累計      累計
 6:00      9.1    18.1      7.5    16.5     +1.6
 8:00      9.5    27.6      9.5    26.0     +1.6
  …
14:00      2.0    43.4      6.0    48.5     −5.1
 途中
16:00       —       —       8.8    59.2       —
```

- 縦は2時間の区間（ラップと同じ12区間、4:00–6:00 … 翌2:00–翌4:00）を始まりの時刻（「8:00」）で書く。横は5列で、すべてポイント（オーナーの案。区間ごとにベストの日と今日の2行を重ねる案・差の行を足す案と比べた）
- 見出しは2段：上に「今日」「ベストの日」「差」、下に「区間」「累計」（2026-10-06 オーナー決定。1段の「区間｜今日｜累計｜ベスト｜累計｜差」と比べた）
- 「区間」はその区間で増えたポイント、「累計」はその区間の終わり（今の区間は今）までにたまったポイント。その日のグラフ（GHO-13）と同じ数え方で、集中・デトックス・睡眠・計画どおりの点のすべてが、付いた時刻の区間に入る（夜の睡眠の点は夜の区間に入る）。なので相手がベストの日なら、最後の累計はその日の合計（ポイントの推移の値）と同じ。開けた時間でポイントが減った区間はマイナスで出す（Claude 補足）
- **赤**：今日が相手（ベストの日・平均・区間ベスト）を上回った数字を赤にする（区間・累計のそれぞれ）。累計の差は今日が前なら赤（+）、後ろなら落ち着いた色。比べるのは画面に出す小数1桁の値で、同じに見えるなら色を付けない。差も画面に出す2つの値の引き算にする（12.0 と 12.0 なら 0.0。別々に丸めて「+0.1」と出ないように）（Claude 補足）。ここの赤は「勝っている」の印（陸上の速報で記録を赤く出すのと同じ）で、負けには使わない。ほかの画面の差の色（前向きな色）は変えない
- 今の区間は下に「途中」と出し、相手も同じ時刻までの値で比べる（Claude 補足）
- まだ来ていない区間は今日の欄を「—」にする。相手の欄は出す（この先の相手のペースが見える。Claude 補足）
- 区間の値が今日も相手も 0.0 の区間は省く（まだ来ていない区間は今日を0とみなす。その日のラップの一覧と同じ。Claude 補足）
- 集中した時間は入れない（2026-10-06 オーナー決定。区間の下に小さく出す案・列を足す案と比べた）。区間ごとの集中は、ベストの日を押して開くその日のグラフのラップ（GHO-06）で見られる
- 文字サイズを標準の最大（設定の目盛りのいちばん右）か、それより大きくしているときは、5列が入らないので区間ごとに縦に並べる。「今日 9.1 ／ 今日の累計 18.1 ／ ベストの日 7.5 ／ ベストの日の累計 16.5 ／ 累計の差 +1.6」を1行ずつ（Claude 補足）
- 開いている間も1分ごとに数え直す（タイマーが動いていれば今の区間が進む。4:00 を過ぎれば新しい今日で比べ直す。ほかの分析の画面と同じ。Claude 補足）

### 区間ベストと理論ベスト（ANA-11、2026-10-06・10-07 オーナー決定。スピードランのゴールドスプリット、F1 の紫のセクターから）
- **区間ベスト**：2時間の区間ごとに、期間の記録のある日の中で、その区間に一番ポイントが増えた日とその値（区間全体の値で比べる。同じなら新しい日。Claude 補足）
- **理論ベスト**：区間ベストをつないだ1日の合計。設定の睡眠の時刻と半分以上重なる区間（ちょうど半分も入れる）は、区間ベストではなく期間の平均（その区間の）を使う（2026-10-07 オーナー決定。睡眠の区間を入れない案・区間ベストを足す案と比べた。夜に起きて集中した日の値を、寝た日と重ねた実際には無理な1日にしないため）。睡眠の区間かどうかは今の設定の時刻で決める（Claude 補足）
- **数え直し**（2026-10-06 オーナー決定「実際のポイントの数え方でもう一度数える」）：つないだ1日で、集中の点の「1日の合計」の倍率（8時間を超えたら×0.75、10時間を超えたら×0.5）を時刻の順にもう一度掛ける。次は Claude 補足
  - 1回の長さ（90分・3時間）の倍率と、開けていた時間の0点は、もとの日のまま（その日に実際に続けた長さなので）。開けていた時間も、もとの日と同じく1日の合計には進む
  - 集中以外の点（デトックス・睡眠・計画どおり）は、もとの日のその区間の値のまま。睡眠の区間は平均の値のまま
  - 睡眠の区間の平均に入っている集中の時間は、1日の合計に入れない（起きている区間でつないだ集中だけで 8時間・10時間を数える。2026-10-07 オーナー決定。入れる案と比べた。平均の点はもとの日ですでに数え終えた値で、夜に集中する日はまれなため）
  - 区間をまたぐ集中は、区間の境目で切って、それぞれの区間の日の分として数える
  - なので区間ベストの表の「区間」は、数え直しで区間ベストの値と少し変わることがある（大きくも小さくもなる）。理論ベストは、まれに自己ベストより低くなる（ベストの日の夜の区間が平均より多かったときなど）
- **金の印**（2026-10-07 オーナー決定）：今日の区間の値が、その期間の区間ベスト（数え直す前の、実際の1日の値）を超えたら、ラップ表の今日の区間の数字の左に、数字と同じ大きさの ★（金色。「★9.1」。2026-10-07 オーナーが画面の案から選んだ。右上に小さく付ける案と比べた。数字の右端が上下の行とそろうため）。相手を何にしていても付ける。夜の区間でも付ける（2026-10-06）。次は Claude 補足
  - 比べるのは画面に出す小数1桁の値で、同じなら付けない（赤と同じ）。今日の値が 0.0 以下なら付けない（区間ベストがマイナスの区間で、何もしなくても付かないように）
  - 今の区間は今までの値で比べる（区間の途中で塗り替えたら付く）。開けた時間で値が下がれば消える。4:00 に新しい今日になれば消える
  - 赤は表の相手の数字と比べ、★ は区間の記録と比べる。相手を区間ベストにしたとき、数え直しで両方の数字がずれる区間では、赤と ★ がそろわないことがある
  - ★ は数字の色を変えない（赤はそのまま）。金は ★ の印にだけ使う（[home.md](home.md) の色の例外）

## 通算記録と節目（ANA-10、2026-10-07 オーナー決定。野球の通算安打から）
- 分析の一覧の一番上に通算の集中した時間・ポイント・記録のある日の数（上の「入口」）
- **節目の帯**：集中した時間の通算が 10・50・100・200・300・500・1000時間（そのあとは500時間ごと）に届いたら、ホームの上に「通算100時間 達成」を出す（ポイントの節目も出す案・帯なしと比べた）。出し方は下の「ホームの帯」
- この機能が入る前に越えていた節目は出さない（入れた日に一度にたくさん出ないように。次の節目から。Claude 補足）
- 一度に2つ以上越えたら（申告でまとめて足したときなど）、一番大きい節目だけ出す。出した節目は端末に覚え、記録を消して通算が減ってからまた越えても、同じ節目は2度出さない（Claude 補足）

## ホームの帯（ANA-08・10、2026-10-07 オーナー決定）
計画どおりの点（GHO-16）の「計画どおり +1pt」と同じ形で、ホームの上に2秒出す。押す操作は増やさない。
- **ベスト更新**：今日のポイントが、自己ベスト・月間ベスト・週間ベストのどれかを超えたとき（同じ値では出さない）、超えた一番上のもの（自己＞月間＞週間の順）を「今週のベストを更新（48.5pt → 52.0pt）」と出す。1つのベストにつき1日1回。そのあと上のベストも超えたら、そのぶんをもう1回出す（1日に多くて3回）。上のものを出したあとに下のものを超えても出さない（2026-10-07 オーナー決定。自己ベストだけ・帯なしと比べた）
  - 比べるのは期間のベスト（今日は入れない）。月曜の今週・1日の今月は比べるベストがないので出さない。記録のある日が1日もないうちは出さない（Claude 補足）
  - 月をまたぐ週では週間ベストが月間ベストより大きいことがある。そのときも順は 自己＞月間＞週間 のまま（Claude 補足）
  - 今日のどこまで出したかは日ごとに端末に覚える（計画どおりの点の帯と同じ）。開けた時間で今日の値が下がってからまた超えても、同じものは2度出さない（Claude 補足）
- **節目**：上の「通算記録と節目」
- 同じ時に2つ以上届いたら、ベスト更新 → 節目 → 計画どおりの点の順に1つずつ出す。アプリを開いていない間に届いたものは、開いたときに同じ順で1回ずつ（ベスト更新は届いた一番上のものだけ。Claude 補足）

## 時間帯の地図（ANA-07、2026-10-04・10-06 オーナー決定）
- 曜日（月〜日）×2時間の区間（ラップと同じ12区間）のマス。色の濃さは、その曜日・区間に集中した時間の平均（直近4週。今日は入れない）。濃いほど集中している
- 下に「よく集中するのは 水曜の 10:00–12:00」（一番濃いマス）と色の目安
- 4週に満たないときは、ある分だけで平均する（記録のない日は0として数えない。Claude 補足、Q39）

## 数え方（Claude 補足）
- 過去の日のポイントは、ホームと同じ計算をその日の記録で毎回やり直す（保存しない）。あとからカテゴリのグループを変えたり記録を直したりすると、過去の数字も変わる（Q33（非公開の判断表）と同じ考え）
- その日の睡眠が保存されていない日は、今の設定の時刻で数える（ホームの「前の日」の扱いと同じ）
- 日付の区切りは朝4:00。0:00〜3:59 に開くと前の日が「今日」
