# つながり（フォロー・インプレッション・応援）

段階4以降（サーバー同期 EXT-01 の後）に作る。今はバックログとして決めたことだけを書く（2026-10-21 オーナー決定、[ADR-0022](../../decisions/0022-public-records-and-cheers.md)）。ほかの人との対戦（GHO-11、[ADR-0017](../../decisions/0017-community-race.md)）とは別の要件で、こちらが先にあってもよい。

## ねらい
SNS が使っている「メタ報酬」（報酬を与えたこと自体が報われる）を、GhostPace の軸（過去の自分との対戦）からずれない形で使う。
- 見られる：自分のベストと今日が誰かに開かれたことが、件数で分かる（インプレッション）
- 応援される：誰かが自分の記録に応援を送ってくれる
- **応援が報われる**：応援した相手があとでベストを更新すると、応援した側に「あなたが応援した○○さんがベスト更新」と返ってくる。ここがメタ報酬
- 同じしくみでメタ罰（mixi の足あとのような「見たのに返さないと失礼」）が生まれないよう、誰が見たかは出さない

## 作る順番
1. アカウントとプロフィール（SOC-01）。同期（EXT-01）の上に作る
2. 記録の公開（SOC-02）とフォロー（SOC-03）、通報とブロック（SOC-07）
3. インプレッション（SOC-04）
4. 応援（SOC-05）
5. 応援が報われる（SOC-06）

## アカウントとプロフィール（SOC-01）
- ニックネームとアイコン。ID（英数字）を1つ持ち、QR コードと ID で見つけてもらう
- 本名は求めない
- アカウントの削除をアプリの中からできる（アカウントを作れるアプリへの Apple の決まり）

## 公開する記録（SOC-02）
- **自己ベスト（1日のポイント、全期間）の日と、今日**の2つ。基本は誰でも見られる（フォローしていない人も）
- 見せるのは**ポイント・ポイントの推移の線・ラップの一覧だけ**。ニックネームとアイコンを添える
- 見せないもの：カテゴリの名前・ブロックの名前・何時に何をしたか・集中した時間・開けた時間・睡眠
- 週間・月間のベストや、ほかの日は公開しない
- 今日の記録は、同期した時点のもの（どのくらいの間隔で送るかは同期の設計で決める）

## フォロー（SOC-03）
- 片方向のフォロー。QR コードか ID で相手を追加するだけで、相手の承認は要らない（記録はもともと誰でも見られるので、承認で隠すものがない）
- フォローの一覧から、相手の今日とベストを開ける。フォローはいつでも外せる
- フォローされたことは通知しない

## インプレッション（SOC-04）
- 自分の今日・ベストを他人が開いたら数える。**1人1日1回**（同じ人が何度開いてもその日は1件）。自分が開いた分は数えない
- 出すのは**件数だけ**。誰が見たかは出さない（メタ罰を生まないため）
- **通知しない**。自分の今日・ベストを開いたときに件数が見えるだけ
- 例「今日の記録　12人が見た」

## 応援（SOC-05）
- 他人の今日・ベストに1タップで応援を送れる。**記録ごとに1回**。もう一度押すと取り消せる
- 受けた側には、件数と**応援した人の名前**を出す（応援は自分で送るものなので、名前が見えても足あとのような圧はない。名前が見えると応援し返す流れが生まれる）。例「応援 3（○○さん・△△さん ほか）」
- 応援されたことは通知しない。自分の今日・ベストを開いたときに見える

## 応援が報われる（SOC-06、メタ報酬）
- 応援してから**7日以内**に、相手が自己ベスト（1日のポイント、全期間）を更新したら、応援した側に「あなたが応援した○○さんがベスト更新」と出す
- **アプリの中だけ**で出し、プッシュ通知はしない
- 出す場所・同じ人が7日以内に何度も更新したとき・取り消した応援の扱いなどの細部は Q45（非公開の判断表）

## 通報とブロック（SOC-07）
- 知らない人どうしでニックネームとアイコンを見せ合うので、Apple の決まりで通報とブロックの仕組みが要る
- ブロックした人とは、互いの記録を開けず、応援も届かない

## SNS にしないための決まり（SOC-08）
GhostPace はゲームと SNS を止めるアプリなので、GhostPace そのものを「確かめに開く」アプリにしない。
- インプレッション・応援・フォローは、プッシュ通知を送らない
- アプリのアイコンのバッジ（赤い数字）も付けない
- 件数は自分の記録を開いたときに見えるだけにする

## 決まっていないこと
Q45（非公開の判断表）：知らない人の見つけ方、公開を止める設定を置くか、インプレッションの件数を区切る単位、応援が報われるの細部、人によってポイントの付き方が違うこと（睡眠・デトックスでも点が付く）を他人に見せてよいか、課金の範囲（PAY-02 との関係）
