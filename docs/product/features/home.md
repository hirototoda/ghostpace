# ホーム画面

## 目的
アプリを開いた瞬間に「先週の自分に勝っているか」が分かり、1タップで集中を始められるようにする。

## 画面の移動（NAV-01、2026-10-01 決定）
画面の下にタブを置き、「タイマー（このホーム）」「計画」「タイムライン」の3つを切り替える。計画のタブでは今日の計画とテンプレートを扱う（[daily-plan.md](daily-plan.md)）。設定はホーム右上の歯車から開く（2026-10-01 決定。4つ目のタブ・各タブの右上と比べて選んだ。[案の比較](../assets/2026-10-01-options-tabs.png)）。MVP の後に「分析」を並べる（ANA-03）。

## 方針
- 型は「大きな数字＋ボタンだけ」。1日のタイムラインはホームに置かず、別の画面に分ける（類似アプリ調査（非公開）の型①と②の中間）
- 1つの状態につき、主な操作は1つ。ボタンは親指が届く画面下部に置く
- 数字は最大3つまで
- 色の意味を固定する（リードしている＝前向きな色、負けている＝落ち着いた色。赤で責めない）

## 見た目の決め方
SwiftUI で2〜3案を実際に作り、シミュレーターのスクリーンショットを報告に載せてオーナーが選ぶ。HTML のモックは作らない（完成品と見た目がずれ、作り直しになるため）。

案どうしで変えるのは**数字の見せ方**（2026-09-30 決定）。色・書体はそろえて比べる。

**決定（2026-09-30）：リング式**。数字だけ・1日の帯の案と比べて選んだ。[スクリーンショット](../assets/2026-09-30-home-ring.png)
- 二重の円。外側＝今日の集中、内側＝先週の同じ曜日の同じ時刻までの集中。1周＝先週の1日分の集中時間
- 円の中に「今日の集中」を大きく、その下に「先週 1時間05分」（相手がこの時刻までに集中した時間）を小さく出す（2026-10-01 からは相手の時間をゴーストの吹き出しに出し、ここは「vs 先週の自分」。GHO-12）
- 円の下に「先週の自分より +25分」。タイマー実行中の画面と同じ作り
- 先週のデータがなく目標（GHO-10）があるときは、目標と対戦する（切り替えは出さない）。先週のデータも目標もない日（計画なし日で目標も決めていない）だけ、1重の円（1周＝今日の計画の集中時間）にし、円の下に「来週から先週の自分と対戦できます」
- 対戦相手は「先週の自分」と「目標」（GHO-10）。円の中の「先週 1時間05分 ⌃⌄」（2026-10-01 から「vs 先週の自分 ⌃⌄」）を押すと「比べる相手」の一覧が下から出て、選んだ相手が内側の円と円の下の差に出る。一覧には相手ごとに「この時刻まで」「1日で」の時間と、今の自分との差を出す（2026-10-01 オーナー案。相手はあとで増やせる。[画面](../assets/2026-10-01-options-owner-ideas.png)）
- 選んだ相手は覚えておき、次の日・アプリを開き直したあとも同じ相手から出す。その相手がいない日（先週のデータがない等）は、いる方を出す
- 対戦の表示は段階ではなくデータの有無で切り替える（先週の同じ曜日の記録があれば出す）
- **マラソン風（2026-10-01 決定、GHO-12・13）**：円をトラックに見立て、自分とゴーストが今の地点を走る。アプリを開くたびに0から今の地点まで走ってくる。ゴーストに吹き出しで相手のこの時刻までの集中。円を押すと裏返ってポイントのグラフ（今のまわりの3時間、［1日］で24時間。詳しくは [ghost-race.md](ghost-race.md)）

## 状態ごとの表示
### タイマー停止中（基本の状態）
| 優先度 | 表示 | 例 |
|---|---|---|
| 1（最大） | 二重の円の中に今日の集中。先週の同じ時刻までの集中はゴーストの吹き出し（GHO-12） | **1時間30分**／吹き出し「先週 1時間05分」 |
| 1 | 円の下に先週の自分との差 | 先週の自分より **+25分** |
| 3（小） | 今日ゲーム・SNS を開けた時間と回数（2026-10-03 からデトックスの時間の代わり。DTX-05、[digital-detox.md](digital-detox.md)）。一度も開けていなければ「開けていない」、ブロックが一度も効いていない日は出さない | 🔓 開けた 25分 ［2回］（回数は札。一度も開けていなければ 🔒 開けていない） |
| — | 今の計画ブロック（なければ次の予定）。タップで計画の変更を開く。次の予定の右に［今から始める］（前倒し。[focus-timer.md](focus-timer.md#計画の時刻より前に始めたいときtmr-1011)） | 次：ゼミ準備 11:00–13:00 › ［今から始める］ |
| 操作 | 開始ボタン。今の計画ブロックがあればブロック終了までのカウントダウンを1タップで開始。なければ「カテゴリを選んで開始」で計画外の開始シートを開く | [ ゼミ準備を開始 ] |

- 画面の右上に設定（[settings.md](settings.md)）の歯車を小さく置く。タイムラインは下のタブに移した

### タイマー実行中
全画面の専用画面に切り替わる。ホームの他の表示・操作は隠し、終了するとホームに戻る。

| 優先度 | 表示 |
|---|---|
| 1 | 円の中に残り時間（カウントダウン）または経過時間（ストップウォッチ）。0を過ぎたら「+3:12 超過」。円は予定時間に対する進み具合 |
| 2 | 先週の自分との差（リアルタイムで更新） |
| 3 | 今のブロック名（カテゴリ） |
| 操作 | 一時停止・終了 |
| 計画外のタイマー中に計画の時刻が来たとき | ボタンの上に「11:00 からゼミ準備の時間です」と［ゼミ準備に切り替える］（TMR-11、[focus-timer.md](focus-timer.md#計画の時刻より前に始めたいときtmr-1011)） |

### 特別な場合
| 場合 | 表示 |
|---|---|
| 計画なし日（朝の計画をスキップ） | 今の計画ブロックの代わりに「計画なし ›」。押すと計画画面が開き、あとから計画を作れる（2026-09-30 決定）。開始ボタンを押すとカテゴリを選んでから始める |
| 先週のデータがない（使い始めの1週間など） | 1重の円にし、差の代わりに「来週から先週の自分と対戦できます」（GHO-03） |
| 夜（振り返りの通知時刻 22:00 を過ぎた後） | 開始ボタンの上に「今日を振り返る」ボタンが現れる（開始ボタンより控えめな見た目）。翌朝4:00まで出る。それ以外の時間は出さない |
| 1分未満で終えた | 上に「1分未満なので記録しませんでした」が2秒出る |
| 保存に失敗した | 「保存できませんでした」のアラート。タイマーは動いたまま、もう一度押せる |
| 記録を開けなかった（起動時） | 「記録を開けませんでした」「記録は消していません」と「もう一度試す」ボタン |
