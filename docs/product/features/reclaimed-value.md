# 取り戻した時間（時給換算）

> **2026-10-02 オーナー決定：作らない。** 取り戻した時間と金額（時給）は、実装する項目から外した。下は記録として残す。

## 目的
「SNS やゲームに流れていた時間を、意味のあることに使えた」ことを、自分の時給で金額にして実感できるようにする。このアプリの売り（[vision.md](../vision.md)）。

## 決まっていること
- **取り戻した時間 ＝ タイマーを動かした時間**。ゲームと SNS はいつもブロックしている（BLK-09）ので、タイマーの時間は取り戻したとみなす。ただし、タイマー中に長押しで開けていた時間は取り戻した時間に含めない（2026-10-01 決定、Q24。開けた時刻と戻った時刻の記録から引く）
- **SNS やゲームの実際の使用時間は測らない**（[ADR-0009](../../decisions/0009-reclaimed-time-no-measurement.md)）
- 一時停止中の時間は含めない
- 取り戻した時間は2段階に分ける。分け方はカテゴリで自動（タイマー開始時に選ばせない）
  - **集中した時間**：「集中時間に数える」カテゴリ（study, work など）のタイマー時間
  - **デジタルデトックスした時間**：それ以外のカテゴリ（rest, housework など）のタイマー時間（2026-10-02 からブロックが効いていた時間で数える。[digital-detox.md](digital-detox.md)）
- **金額にするのは集中した時間だけ**。金額 ＝ 集中した時間 × 時給。時給は1つだけ設定する。デトックスは時間だけ見せる
- 見せ方はプラスの言い方のみ。例：「今週 集中 2時間 ＝ 2,400円分／デトックス 1時間」
- ブロック対象のアプリ＝無駄時間の対象アプリとみなし、別の設定は作らない
- ホーム画面で一番大きく見せる数字は「先週の自分との差」（[ghost-race.md](ghost-race.md)）。取り戻した額はその次に置く

## 表示例
| 場所 | 表示 |
|---|---|
| ホーム | 今日 集中 1時間30分 ＝ 1,800円分／デトックス 30分 |
| 日次振り返り | 今日の集中（時間・金額）とデトックス（時間） |
| 週次振り返り（段階3） | 今週の合計、先週との比較 |
