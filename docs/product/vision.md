# ビジョン

## 一文で
朝に立てた計画で自分を守り、その記録で過去の自分と戦い、振り返りで行動を変えるための、自分専用の時間管理アプリ。

## 解決したい不満
Opal や Focus Plant は「その場の集中」は助けてくれるが、**分析が浅く、振り返りに使えない**。
記録が溜まっても「で、明日から何を変えるか」につながらない。
やることが増えて複雑になると、記録するだけのアプリでは時間の使い方が見えなくなる。

## 他アプリとの違い（売り）
**取り戻した時間を、自分の時給で金額にして見せる。**（2026-10-02 オーナー決定：作らない。デトックスはブロックが効いていた時間をポイントにし、画面には開けた時間を出す。ADR-0018）
タイマー中は SNS やゲームを使えなくするので、タイマーを動かした時間＝ SNS やゲームから取り戻した時間とみなす。
休憩などでタイマーを使った時間は「デジタルデトックス」として別に見せる（2026-10-01 決定：ゲームと SNS のブロックが効いていた時間をデトックスとして数えるように切り替える。[features/digital-detox.md](features/digital-detox.md)）。
例（金額は作らないことになった）：「今週 集中 2時間 ＝ 2,400円分／デトックス 1時間」。詳細は [features/reclaimed-value.md](features/reclaimed-value.md)。

## 答えたい問い
振り返りで次の問いに答えられることを、全機能の判断基準にする。
1. 何（カテゴリ・プロジェクト・作業種別）に時間を使ったか
2. 計画と実績のズレはどこで生じるか
3. どの時間帯・曜日に集中できているか
4. 過去の自分と比べて、今どこにいるか（例：1週間前のこの時刻より何分多く集中しているか）

## 原則
- **記録が主役、ゲームは可視化の延長**：ゲーミフィケーションは育成や報酬ではなく、自分のデータを見せる形で行う
- **強制より情報**：ブロックしたアプリもいつでも開ける。ただし3秒長押しして5秒待ち、その間に先週の自分との差を見る（[ADR-0013](../decisions/0013-hold-to-unlock.md)）。開いたことは全て記録し、段階3で対戦と分析に使う
- **計画は朝に一度**：その日最初に開いたときに立てる。朝の版は必ず保存し、予実比較の基準にする
- **データを溜めることが最優先**：機能が未完成でも、記録だけは初日から正しく残す
- **まず自分用、後で公開**：最初は自分だけで1〜2か月使って効果を確かめる。手応えがあれば App Store 公開を検討する（[ADR-0008](../decisions/0008-personal-first-publish-later.md)）。公開の基準・価格・時期は売り方の資料（非公開）にある。同期やNotion連携も後から足せる構造にする
