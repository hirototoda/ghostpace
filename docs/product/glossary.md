# 用語集

| 用語 | 意味 |
|---|---|
| その日の区切り（日付境界） | 一日の終わりの時刻（初期 22:00、設定で変えられる。GHO-17）。この時刻でその日の結果が確定し、より後は次の日の分になる。例：区切り 22:00 なら一日は 10/20 22:00〜10/21 22:00。端末の暦の壁時計の時刻で決める。設定を変えた次の日の長さ・日ごとの履歴・変える前の日（4:00 区切り）・夏時間と旅行の扱いは [data-model.md](../design/data-model.md)「DayBoundaryChange」（[ADR-0023](../decisions/0023-day-boundary-evening.md)。2026-10-21 に朝4:00から夜に変えた。それまでは「4:00。3:59までは前日」） |
| 日の名前（dayKey） | その一日を呼ぶ日付。その一日の中にある 12:00 の暦の日で、週・月・曜日もこれで決める。例：10/20 22:00〜10/21 22:00 は「10/21」。区切りが夜中（0:00〜翌4:00）のときの例は [data-model.md](../design/data-model.md)「DayBoundaryChange」（Claude 補足、Q48（非公開の判断表）） |
| 同じ時刻でそろえる | 先週の自分・自己ベストの日など、ほかの日と比べるときの合わせ方（GHO-02）。日の名前の日の 0:00 からの壁時計の時刻でそろえる。例：今日の前の夜 22:30 は、相手の日の前の夜 22:30。区切りが違う日の扱いは [ghost-race.md](features/ghost-race.md)「区切りを変えた週」（Claude 補足、Q48） |
| 朝の計画を出す時刻 | 朝4:00。朝4:00以降に、その日に初めて開いたときに朝の計画を出す（PLN-01）。区切りの設定とは関係なく決まっている（2026-10-21 オーナー決定） |
| 計画（DailyPlan） | その日の予定一式。朝に確定する |
| 計画ブロック（PlanBlock） | 計画の1コマ。開始・終了時刻とカテゴリを持つ |
| 習慣 | 毎日決まった時刻にすること（ゲーム・SNS の時間とほかのブロック、各3つまで）。新しく作る計画の下書きに自動で入る（PLN-08） |
| 候補 | 昨日・先週の同じ曜日の計画とテンプレートのブロック。押すと同じ時刻で今日に足せる（PLN-09） |
| スナップショット | 朝に確定した時点の計画の写し。後で計画を変えても残る |
| 集中セッション（FocusSession） | タイマーを動かした実績の1回分 |
| 計画外セッション | 計画ブロックにひも付かないセッション |
| カテゴリ | 生活のどの領域か（study, work, rest など）。必須 |
| プロジェクト | 取り組む対象（EduAI、院試など）。任意 |
| 作業種別 | 何をしたか（実装、読書、課題など）。任意 |
| 集中時間 | 「集中時間に数える」カテゴリのセッション合計。restなどは含まない |
| 中断 | セッション中の一時停止 |
| 計画どおりに進んだ割合 | 朝に計画した時間のうち、実際にタイマーを動かせた割合。ゴーストレースの項目の1つ |
| ゴースト | 対戦相手としての過去の自分の記録 |
| ゴーストレース | 当日の累積集中時間を、ゴーストの同時刻の値と比べること |
| シールド | ブロック中のアプリを開いたときに出るブロック画面 |
| 開く（解除） | シールドの「開く」から GhostPace で3秒長押しして5秒待ち、選んだ長さ（5分〜1時間）だけブロックを外すこと。禁止はせず、すべて記録する（[ADR-0013](../decisions/0013-hold-to-unlock.md)） |
| いつものブロック | ゲームと SNS に24時間かかっているブロック（BLK-09） |
| 自動ブロック | 計画ブロックの時間帯に追加でかかるブロック（段階2） |
| 集中中の全部ブロック | 集中のタイマー中（一時停止を除く）に、集中中も使うアプリ以外の全部にかかるブロック（BLK-04。以前の「拡張ブロック」） |
| 集中中も使うアプリ | 集中中の全部ブロックから外すアプリのリスト（例：Kindle。BLK-02） |
| ゲーム・SNS の時間 | 朝の計画で決めた、いつものブロックを外す30分（1日3つまで。BLK-10）。デトックスとしてはそのまま数える |
| 取り戻した時間 | タイマーを動かした時間。タイマー中は SNS やゲームをブロックするので、そこから取り戻した時間とみなす。実際の SNS 使用時間は測らない。集中した時間とデジタルデトックスした時間の合計 |
| デジタルデトックスした時間 | いつものブロックが効いていた時間（長押しで開けた時間・集中のタイマー中を除く。ゲーム・SNS の時間と寝ている間は含む）。金額にはしない（[digital-detox.md](features/digital-detox.md)、[ADR-0014](../decisions/0014-detox-is-blocked-time.md)。2026-10-02 に切り替えた。それまでは「集中時間に数えない」カテゴリでタイマーを動かした時間） |
| 取り戻した額 | 集中時間 × 時給。「◯円分」とプラスの言い方で見せる |
| 時給 | 金額換算に使う値。オーナーが1つ設定する |
| フォロー | QR コードか ID で相手を追加すること。片方向で、相手の承認は要らない（SOC-03） |
| インプレッション | 自分の今日・ベストを他人が開いた件数。1人1日1回で数え、誰が見たかは出さない（SOC-04） |
| 応援 | 他人の今日・ベストに1タップで送るもの。記録ごとに1回（SOC-05） |
| メタ報酬 | 報酬を与えたこと自体が報われること。GhostPace では、応援した相手がベストを更新すると応援した側に返ってくる（SOC-06） |
