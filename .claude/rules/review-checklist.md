# GhostPace のレビュー観点

review-3（review-correctness / review-design / review-coverage）でこのリポジトリを見るときは、グローバルのチェックリストより**この文書を優先**する。グローバルにある Web 向けの項目（テナント分離、ロール別、SQLi/XSS/CSRF、ブラウザ確認手順書、N+1）は、このアプリには当てはまらないので見ない。

前提：iPhone 用の個人アプリ（SwiftUI / SwiftData / オフライン）。オーナーはコードを読まず、docs と画面だけで判断する。仕様の正は docs/。

## 正確性（review-correctness）
### コード
- **現在時刻**：`Date()` や `.now` を直接呼んでいないか（例外は `SystemClock` と `TimelineView` の開始時刻だけ）。時刻は `AppClock` 経由
- **日付の区切り**：「今日」を朝4:00で区切っているか（`DayBoundary`）。0:00〜3:59 が前日扱いになるか。`dayKey` を開始時刻から出しているか
- **タイムゾーン・夏時間**：UTC で保存し、表示は端末のタイムゾーン。`Calendar` は注入されたものを使うか
- **経過時間**：開始時刻（と一時停止の区間）から毎回計算しているか。アプリの終了・バックグラウンド・端末の再起動のあとも正しいか（TMR-02）
- **記録を失わない**（NFR-02）：SwiftData のモデルを変えたら、VersionedSchema と MigrationPlan で古いデータを移しているか。消すのではなく削除の印（isDeleted / isArchived）で残すべきものを消していないか
- **朝のスナップショット**（PLN-03）：確定後の変更で書き換わっていないか
- **集中とデトックス**：`countsAsFocus` で分けているか。デトックスを集中時間や金額に入れていないか
- **並行処理**：Swift 6 の警告（MainActor・Sendable）を黙らせるだけの修正になっていないか
- **Repository 経由**：View から SwiftData（ModelContext・@Query）を直接触っていないか

### 仕様（docs）
- features/*.md・requirements.md・data-model.md・非公開側の open-questions.md の決定済み表のあいだで矛盾がないか
- 公開側（このリポジトリ）に、個人の情報・値段・自分の数字・秘密の情報を書いていないか
- 状態の抜け：一時停止中、4:00をまたぐ、計画なし日、先週のデータがない日、アプリを消して入れ直した場合

## 設計・整合性（review-design）
- **docs と実装が合っているか**：振る舞いを変えたのに docs を直していない PR は major
- 要件ID がコミット・PR・docs でそろっているか
- オーナーが決めていないことを、実装で勝手に決めていないか（決めたなら非公開側の open-questions.md に記録があるか）
- **操作の手数**：1つの状態につき主な操作は1つ（home.md）。確認や入力を増やしていないか
- 色の意味（Theme）：リードは前向きな色、負けは落ち着いた色。赤で責めない
- `*.xcodeproj` を直接いじらず `project.yml` を直しているか
- 使われない抽象化・見本用のコードが本番の経路に残っていないか（DEBUG で囲む）
- オーナー向けの文書（features・非公開側の報告・open-questions）が、コードを読まない人に分かる日本語か

## 網羅性（review-coverage）
振る舞いごとに、次のテストがあるかを表にして確かめる。
- 正常系と、境界：**3:59 / 4:00**、0分・1分未満、長さの上限（3時間）、ブロックがくっつく／重なる
- 時間の経過：`FixedClock`・`OffsetClock` で「30分後」「翌朝」「1週間後」を再現しているか
- データ移行：スキーマを変えたなら、古い版のデータを読めるテスト
- 画面：主な操作の流れが変わったなら UI テスト（FocusAppUITests）が1本あるか。ダーク・文字サイズ最大のスクショが報告にあるか
- 実機でしか確かめられないもの（通知の届き方、Screen Time、再起動）が、報告の「オーナーにお願いしたいこと」に手順として書かれているか
- 受け入れ基準（docs/verification/acceptance/）の結果欄が更新されているか
