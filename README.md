# GhostPace

個人用の iPhone 時間管理アプリ。朝の計画 → 自動ブロック → 集中タイマー → 記録 → 過去の自分との対戦・振り返り。
SwiftUI / SwiftData / XcodeGen。

- 仕様・設計・判断の記録は [docs/](docs/README.md) にある
- 開発は Claude Code が行い、オーナーはドキュメントと画面で確認・判断する
